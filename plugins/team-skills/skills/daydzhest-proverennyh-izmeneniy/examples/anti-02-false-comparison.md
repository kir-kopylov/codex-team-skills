# Анти-пример: ложное «раньше → сейчас»

## Вход

Раньше задачу можно было выполнить через API разработчику с ключом; теперь похожая кнопка появилась в чате для обычного пользователя. Обе фразы подтверждены, но условия доступа разные.

## Ожидаемое Поведение

Дайджест пишет: «Появился ещё один путь через чат для обычного пользователя», отдельно называя условия. Если связь условий не доказана, он не строит переход «раньше было нельзя → теперь можно».

## Нельзя

Не создавать впечатление, будто чат заменил API для той же роли, и не называть ссылку «Открыть чат с контекстом», если передача контекста не проверена.
