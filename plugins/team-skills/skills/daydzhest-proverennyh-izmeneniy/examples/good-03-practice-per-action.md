# Хороший пример: практика для каждого действия

## Вход

Одна новость содержит две подтверждённые возможности: экспорт CSV и настройку расписания. Для экспорта есть безопасный документированный шаг; для расписания передан только факт, без инструкции и теста.

## Ожидаемое Поведение

Под экспортом есть его собственная практика с условием, шагами и критерием успеха. Под расписанием написано: «Практика: безопасный путь не передан». Статус непроверенной или отсутствующей практики не подменяется красивой кнопкой.

## Нельзя

Не использовать ссылку на экспорт как будто она объясняет настройку расписания, и не называть непроверенный путь «проверенной практикой».
