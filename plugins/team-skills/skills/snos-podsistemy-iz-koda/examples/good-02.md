# Хороший Пример: Вывод Scheduler Из Эксплуатации

## Вход

Команда решила удалить локальный scheduler, который периодически запускает maintenance-команду. Поддерживаемым путём остаётся явный запуск той же команды оператором.

## Ожидаемое Поведение

Codex картирует создание, запуск и удаление задачи для каждой поддерживаемой ОС, config keys, service files, package hooks, docs и tests. Он удаляет runtime и регистрацию из новых установок, а для точных owned identifiers оставляет ограниченную одноразовую очистку старых задач.

Проверка разделена: negative scan доказывает отсутствие нового scheduler в package, живая проба доказывает, что ручная команда всё ещё выполняет outcome, а проверка legacy-host подтверждает удаление только owned-задачи. Неизвестный похожий task остаётся нетронутым.

## Нельзя

Нельзя удалять задачи по частичному совпадению имени, считать source cleanup доказательством состояния host или добавлять новый daemon для наблюдения за удалением старого.
