# Неоднозначный адрес

Все значения в примере синтетические.

## Вход

На Тестовой свободно завтра? В свежем результате есть две действующие квартиры с этим названием.

## Ожидаемое Поведение

Использовать известный контекст для выбора. Если он не определяет квартиру, спросить только различающий её номер; не выдавать свободу одной квартиры за свободу другой.

## Нельзя

Выбирать первую строку; спрашивать пароль; считать неизвестный статус отменой.
