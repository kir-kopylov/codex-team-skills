# Приватный Профиль Подключения

Профиль создаётся один раз на разрешённом компьютере вне репозитория. В нём нет пароля: только расположение уже существующего файла настроек и точные имена секции и ключа. Сам файл настроек нельзя выводить в чат или добавлять в библиотеку.

Скрипт ищет профиль в `-ConfigPath`, затем в `EHOUS_BOOKING_CONFIG`, затем в `~/.codex/ehous-booking.json`. Не меняйте глобальные настройки ради проверки. Относительные пути в профиле разрешаются относительно его папки.

Обязательные непустые строки: `DataSource`, `Database`, `UserID`, `ClientDllPath`, `PasswordIniPath`, `PasswordIniSection`, `PasswordIniKey`. Дополнительно: `Port` (по умолчанию 3050), `Charset` (по умолчанию WIN1251). Все значения берите из подтверждённой локальной настройки, а не из публичного примера. Файл профиля не должен содержать поле с самим паролем.

Используйте установленную доверенную библиотеку `FirebirdSql.Data.FirebirdClient.dll` версии 10.3.4 для .NET 8. Исполняемые библиотеки и пароли не поставляются в публичном навыке. При отсутствии клиента сначала сообщите это; установка отдельной зависимости не должна происходить скрыто в каждом запросе.

`PasswordIniSection` и `PasswordIniKey` определяют ровно один пароль существующей конфигурации. При нуле или нескольких совпадениях скрипт прекращает работу до подключения. Не брать первый попавшийся ключ Password из неизвестной секции. Доступная учётная запись не разрешает запись: скрипт открывает только читающую транзакцию.

Выполните проверку профиля без подключения к базе:

```powershell
& '<папка навыка>/scripts/check-booking.ps1' -ConfigPath '<приватный профиль>' -ValidateOnly
```

После настройки повторные запросы сразу используют этот профиль. Проверка профиля подтверждает только чтение настроек и загрузку клиента; доступность сервера доказывается обычным запросом с DB_TIME.
