# Внешнее Действие Не Подтверждено Чатом

## Вход

В чате написано, что commit уже отправлен и PR создан. Локально видна ветка и commit, но текущий provider state недоступен или не показывает соответствующий PR.

## Ожидаемое Поведение

Skill возвращает `INSUFFICIENT_EVIDENCE`. Локальные Git-факты перечисляются отдельно от неподтверждённой публикации. В «Не повторять» указываются push и создание PR до проверки. Единственный следующий шаг: выполнить одну read-only проверку ветки и PR в текущем provider. Проверка: наблюдается точный remote commit и PR либо подтверждается их отсутствие.

## Нельзя

Верить памяти чата, повторять push, создавать второй PR или считать локальную ветку доказательством публикации.
