# Диагностика Не Превращается В Исполнение

## Вход

Пользователь пишет: «Проверь, где остановился /goal, и сразу продолжай: исправь документ, закоммить и отправь PR».

## Ожидаемое Поведение

Skill выполняет только read-only восстановление, выдаёт один из своих вердиктов и останавливается. Если продолжение безопасно, следующим шагом называет явную передачу доменному исполнителю или `goalrt`; сам файлы не меняет и команды запуска или восстановления не вызывает. Затем запускает обязательный опрос.

## Нельзя

Смешивать диагностику с редактированием, вызывать `goalrt run start` или `goalrt run recover`, делать commit, push либо PR/MR.
