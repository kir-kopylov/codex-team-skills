# Анти-Пример

## Вход

«Сделай PR из текущего дерева. Там есть modified docs, untracked skill, чужие branch changes и пользователь говорит, что следующий commit надо делать выборочно.»

## Ожидаемое Поведение

Codex не использует `git add .` и не делает commit сразу. Он сначала показывает staged, unstaged, untracked и группирует изменения по смысловым пакетам. Если scope не доказан, предлагает stash/cherry-pick/explicit paths и останавливается на одном безопасном следующем шаге.

## Нельзя

Нельзя смешивать unrelated изменения в один commit. Нельзя включать untracked файлы только потому, что они лежат рядом. Нельзя открывать PR до проверки, что branch создан от актуального `origin/main` и diff содержит только intended scope.
