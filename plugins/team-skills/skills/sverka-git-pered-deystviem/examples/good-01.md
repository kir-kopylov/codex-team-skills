# Хороший Пример: Перед Commit

## Вход

«У меня рабочее дерево всё ещё грязное, поэтому любой следующий commit надо делать выборочно. Что в рабочем дереве сейчас и что с этим целесообразно сделать?»

## Ожидаемое Поведение

Codex сначала проверяет target repo и выполняет только read-only команды: `status --short --branch`, `diff --stat`, `diff --cached --stat`, `stash list`, `branch -vv`. Ответ разделяет staged, unstaged, untracked и веточное состояние. Если staged пустой, Codex прямо говорит, что `commit` ничего не возьмет без явного `git add`. Если изменения смешанные, Codex не предлагает `git add .`, а группирует файлы по смысловым patch set и называет безопасный следующий шаг.

## Нельзя

Нельзя сразу staging/commit. Нельзя смешивать «грязное рабочее дерево» с локальными ветками `ahead/behind`. Нельзя давать команды без target repo, если текущая папка не подтверждена.
