# Хороший Пример: Команда Запущена Не В Том Каталоге

## Вход

Пользователь показывает терминал: `git branch -d old-branch` вернул `fatal: not a git repository`, хотя раньше Codex рекомендовал эту команду.

## Ожидаемое Поведение

Codex не спорит с ошибкой и не повторяет ту же команду. Он фиксирует расхождение: команда была запущена из папки без `.git`, а целевой repo другой. Дальше он даёт безопасную форму с `git -C <repo> branch -d old-branch` или предлагает сначала `cd <repo>`, затем проверяет `branch -vv`. Если target repo неизвестен, Codex просит путь или ищет кандидатов read-only.

## Нельзя

Нельзя считать ошибку проблемой git-команды, если не проверен cwd. Нельзя предлагать destructive fallback. Нельзя использовать реальные личные пути в reusable example.
