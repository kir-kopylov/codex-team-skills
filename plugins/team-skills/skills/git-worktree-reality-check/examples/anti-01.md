# Анти-Пример: Чисто Учебный Git-Вопрос

## Вход

«Что такое rebase и чем он отличается от merge?»

## Ожидаемое Поведение

Skill не захватывает задачу. Codex отвечает как на учебный вопрос без запуска repo-команд, потому что пользователь не просит действовать в конкретном repo и следующее действие не зависит от текущего worktree state.

## Нельзя

Нельзя запускать reality check ради каждого теоретического слова про git. Нельзя просить путь к repo, если пользователь хочет только объяснение концепции.
