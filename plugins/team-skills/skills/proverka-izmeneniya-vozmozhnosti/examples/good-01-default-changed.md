# Хороший пример: смена default

## Вход

«В версии 2.0 написано: “режим проверки включён автоматически”. В версии 1.9 документация перечисляет тот же режим и говорит, что его надо включить флагом. Можно написать: “теперь появилась проверка”?»

## Ожидаемое Поведение

Skill фиксирует один результат: проверка запроса. Обе версии поддерживают его в одинаковом продукте; меняется только автоматическое включение. Вердикт — `DEFAULT_CHANGED`. Корректная фраза: «Раньше проверку можно было включить вручную; теперь она включается по умолчанию». Источники и условия остаются рядом с выводом.

## Нельзя

Не писать «появилась проверка», «теперь можно проверять» или «раньше было нельзя проверять».
