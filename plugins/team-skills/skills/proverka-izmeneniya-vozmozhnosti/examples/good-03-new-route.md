# Хороший пример: новый путь, не обязательно новый результат

## Вход

«Теперь в чате есть кнопка “Скачать журнал”. Раньше журнал можно было получить через API, но только разработчику с ключом. Можно ли сказать, что скачивание журнала появилось?»

## Ожидаемое Поведение

Skill сравнивает не название кнопки, а результат и условия доступа. Если чат открывает тот же журнал обычному пользователю без ключа, это `EXPANDED`: «Журнал стал доступен ещё и через чат без API-ключа». Если условия не доказаны, остаётся `UNKNOWN`.

## Нельзя

Не называть кнопку `ADDED` только потому, что её не было в старом интерфейсе, и не скрывать различие между доступом через API и чат.
