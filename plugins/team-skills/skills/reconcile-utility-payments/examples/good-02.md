# Хороший Пример: Пересекающиеся Скриншоты

## Вход

На первом скриншоте видны январь–март, на втором — март–май. Строка марта на обоих изображениях совпадает. Пользователь просит добавить новые месяцы и пересчитать.

## Ожидаемое Поведение

Skill объединяет данные по периоду, учитывает март один раз, располагает январь–май хронологически и пересчитывает весь набор через скрипт. Если значения марта различаются, вместо расчёта показывает конфликт.

## Нельзя

Нельзя складывать оба скриншота целиком, повторно учитывать март или молча выбирать одно из конфликтующих значений.
