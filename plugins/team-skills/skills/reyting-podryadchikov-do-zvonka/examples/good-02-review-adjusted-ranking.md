# Хороший Пример: Переранжирование По Отзывам

## Вход

Пользователь пишет: "Теперь проверь этот список отзывами с платформ, где есть отзывы, и переранжируй с учётом реальных отзывов от реальных людей."

## Ожидаемое Поведение

Codex не заменяет исходную операционную оценку простым рейтингом платформы. Он ищет отзывы по точному названию, домену, адресу, юрлицу или устойчивой связке бренда, затем разделяет сигналы: независимый локальный платформенный след, собственные отзывы сайта, релевантный отзыв по похожему сложному кейсу, общий отзыв по обычной услуге и красные флаги вроде чужих городов, будущих дат или копипасты. Итоговая таблица показывает базовый балл, review adjustment, новый балл и причину изменения.

## Нельзя

Нельзя считать отзыв по обычной уборке, клопам, доставке или ремонту доказательством сложного санитарного кейса. Нельзя смешивать одноимённые компании и филиалы без проверки связи. Нельзя писать "реальные люди подтвердили", если это только публичная платформа с ограниченной видимостью и без верификации личности автора.
