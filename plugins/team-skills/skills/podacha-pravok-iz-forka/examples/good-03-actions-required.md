# Хороший Пример: Actions Требуют Разрешения

## Вход

PR открыт, но checks не зеленые. В GitHub написано `action_required`, jobs нет. Пользователь спрашивает: `Это значит, что skill плохой?`

## Ожидаемое Поведение

Skill объясняет, что для PR из fork GitHub может требовать ручного разрешения workflow владельцем repo. Это еще не падение тестов и не доказательство ошибки в skill.

Дальше skill делает или предлагает:

- проверить PR URL и head commit;
- посмотреть workflow runs и jobs;
- если jobs нет и status `action_required`, написать владельцу repo, что нужно разрешить Actions для PR;
- не называть PR полностью проверенным, пока workflow не запущен или maintainer явно не подтвердил другой порядок review.

## Нельзя

Нельзя утверждать, что тесты прошли или упали, если workflow даже не стартовал. Нельзя советовать править код только из-за `action_required`.
