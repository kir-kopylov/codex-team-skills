# Хороший Пример: Fork Уже Создан

## Вход

Я открыла fork `codex-team-skills` в своем аккаунте. Директор просит отправить мой skill в командный repo через Pull Request. Я не понимаю, он уже увидел это или нет.

## Ожидаемое Поведение

Skill объясняет, что fork сам по себе не является PR и обычно не уведомляет владельца upstream repo.

Дальше skill проверяет или ведет пользователя:

- upstream repo: `kir-kopylov/codex-team-skills`;
- fork repo: repo пользователя;
- branch с изменениями: не `main`, а `agent/<short-task>`;
- существует ли уже PR из этой ветки.

Если PR уже есть, skill дает ссылку и проверяет reviewers/checks. Если PR нет, открывает или объясняет маршрут `Contribute` -> `Compare & pull request` -> `Create pull request`.

В конце пользователь получает готовую формулировку для директора: `Я открыла PR: <ссылка>. Посмотрите, пожалуйста.`

## Нельзя

Нельзя говорить, что директор увидел fork как заявку на добавление skill. Нельзя создавать второй PR, если открытый PR по этой же ветке уже существует.
