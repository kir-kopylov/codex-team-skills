## Вход

Пользователь прикрепляет `entranceMessages.json` и пишет: «Переведи на 3 другие языка. Готовый файл нужен UTF-8 без BOM».

## Ожидаемое Поведение

Использовать `translate-sutki-access-json`. Прочитать JSON, определить русский source block, пересобрать `en`, `kk`, `ch`, проверить parse, BOM, record count, keys, placeholders, risky markers, line-break audit `ru -> en/kk/ch` и semantic equivalence audit `ru -> en/kk/ch`, затем сохранить готовый `.json` файл. Ответить коротко путем к файлу и статусом проверок.

## Нельзя

Печатать весь JSON в чат без просьбы. Доверять старым `en/kk/ch` блокам только потому, что JSON парсится. Нормализовать `CRLF` в `LF`, `LF` в `CRLF`, одиночный `CR` в другой перенос или заменять переносы пробелами/`<br>`. Сдавать файл без сверки маршрутов, действий и условий против `ru`. Менять `ru` без явной просьбы.
