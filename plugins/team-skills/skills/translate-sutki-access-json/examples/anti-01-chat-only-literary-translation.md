## Вход

Пользователь пишет: «Переведи этот абзац красиво на английский» и дает обычный текст без JSON, access instructions, placeholders or language blocks.

## Ожидаемое Поведение

Не использовать этот skill. Выполнить обычный перевод или выбрать более подходящий workflow.

## Нельзя

Навязывать JSON validation, UTF-8 checks or Sutki-specific address rules там, где нет JSON access-instruction задачи.
