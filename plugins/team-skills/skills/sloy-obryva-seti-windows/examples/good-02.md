# Хороший Пример: App Proxy И Windows Proxy Расходятся

## Вход

Пользователь пишет: "Браузер работает через системный proxy, но десктопное приложение всё равно пишет connection failed. Внутри приложения есть собственная настройка proxy, я не понимаю, какой слой оно использует."

## Ожидаемое Поведение

Skill отделяет Windows proxy от app proxy config. Он просит или получает свежий скрин настроек приложения, затем проверяет только те системные данные, которые помогают выбрать следующий эксперимент. В выводе появляется layer verdict:

```text
user-visible app UI: connection failed
app proxy config: неизвестно, нужен свежий скрин
Windows proxy: наблюдение из PowerShell, не прямой факт для app
next experiment: зафиксировать app proxy mode и проверить один режим
```

Если пользователь разрешает изменение, skill предлагает один обратимый переключатель и ожидаемое наблюдение.

## Нельзя

Нельзя сразу сбрасывать системный proxy, DNS или firewall. Нельзя смешивать app-level proxy с Windows proxy в одну причину без проверки интерфейса приложения.
