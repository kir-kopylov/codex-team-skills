# Анти-Пример: PowerShell Выдан За Реальность GUI

## Вход

Пользователь пишет: "Telegram не подключается". Агент запускает `curl` из PowerShell, получает успешный ответ и говорит: "С сетью всё в порядке, Telegram должен заработать после перезапуска".

## Ожидаемое Поведение

Skill должен остановить такую подмену. Корректный вывод: PowerShell доказал только состояние своего слоя. Для Telegram нужны отдельные наблюдения: свежий UI, настройки Telegram proxy, процесс/сокеты, DNS/route/VPN и прямое evidence успешного подключения.

## Нельзя

Нельзя считать CLI-тест прямым доказательством GUI-приложения. Нельзя объявлять цель закрытой без свежего evidence из самого приложения или подтверждения пользователя.
