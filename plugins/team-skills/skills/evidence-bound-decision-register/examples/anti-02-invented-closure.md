# Анти-Пример: Выдуманное Закрытие

## Вход

Часть вопросов требует реального файла и решения уполномоченной роли. Файла нет, а роль ещё не выбрала правило. Агент видит правдоподобную схему и хочет повысить процент закрытия.

## Ожидаемое Поведение

Факты без файла остаются `UNKNOWN` с `[needed:...]`, решения на их основе — `PENDING_CONTEXT`, а несовместимые ответы — `CONFLICT`. `MISSING` source не становится evidence. Даже после структурного validate принятые строки остаются `UNREVIEWED`, пока отдельный review event не зафиксировал reviewer и basis.

## Нельзя

Нельзя заменить отсутствие файла словами «по стандартной практике», переписать fingerprint/history под старый ID или считать `STRUCTURALLY_VALID_SEMANTICALLY_UNREVIEWED` готовностью.
