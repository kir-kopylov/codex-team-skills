# Хороший Пример: Цепочка До Отсутствующего Источника

## Вход

Для выбора правила импорта нужно знать полный перечень типов строк из исторического экспорта. Пользователь знает, где хранится экспорт, но сам файл не передан. Два последующих решения зависят от перечня, а третье зависит от одного из них.

## Ожидаемое Поведение

Manifest содержит `historical-export` с availability `MISSING`. Фактический вопрос получает `UNKNOWN`: `не знаю — перечень устанавливается из исторического экспорта`, evidence `[needed:historical-export]`. Все зависимые строки получают `PENDING_CONTEXT`, точные `depends_on` и равные им ссылки `[decision:...]`. Итеративный валидатор показывает этот корень первым по числу зависимых строк.

## Нельзя

Нельзя восстановить перечень «по типовым случаям», записать `[evidence:historical-export]` до появления bytes/hash или пометить зависимые решения `DERIVED`. Ранжирование измеряет только число зависимых строк.
