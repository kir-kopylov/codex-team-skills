# Хороший Пример: Один Ответ Закрывает Несколько ID

## Вход

Пользователь одним сообщением определил, кто выполняет еженедельную проверку, кто контролирует результат и какое подтверждение закрывает спор. В реестре это три разных вопроса, причём последний зависит от первых двух.

## Ожидаемое Поведение

Skill регистрирует один `OBSERVED` source `user-turn-11`, связывает с ним три отдельные строки через `[evidence:user-turn-11]` и добавляет три hash-chain events. Ответ каждого ID остаётся буквальным. После смысловой проверки reviewer создаёт отдельные review events; следующий вопрос выбирается только среди действительно незакрытых бизнес-решений.

## Нельзя

Нельзя обновить только последний ID, переписать CSV без history или скопировать один общий абзац во все строки, если он не отвечает отдельно на каждую формулировку.
