## Вход

Пользователь прикладывает файл `entranceMessages.json` и пишет: «Переведи на три других языка. Готовый файл нужен в `UTF-8` без `BOM`».

## Ожидаемое Поведение

Прочитать файл, найти русский исходный блок, заново собрать `en`, `kk`, `ch`, проверить разбор файла, отсутствие `BOM`, число записей, совпадение ключей, плейсхолдеры, опасные маркеры, сверку переносов строк и сверку смысла для `ru` и каждого целевого языка, затем сохранить готовый файл. Ответить коротко: путь и статусы проверок.

## Нельзя

Печатать весь файл в чат без просьбы. Доверять старым блокам `en`, `kk`, `ch` только потому, что файл разбирается. Превращать `CRLF` в `LF`, `LF` в `CRLF`, терять одиночный `CR` или заменять переносы пробелами и тегом `<br>`. Сдавать файл без сверки маршрутов, действий и условий с русским источником. Менять блок `ru` без явной просьбы.
