# Хороший Пример: Прозрачный Автозапуск

## Вход

Пользователь просит доработать `goal-contract-shaper`: согласовать требования, примеры и тесты.

## Ожидаемое Поведение

При однозначном смысловом совпадении Codex показывает одну контекстную строку:

Применяю **«Подготовку командного навыка»**: согласую требования, примеры и тесты для доработки; продолжаю без ожидания.

В том же ответе Codex начинает работу. Уведомление объясняет дополнительную процедуру, но не запрашивает подтверждение внутреннего метода и не показывает автора готового навыка.

## Нельзя

Нельзя останавливать чат ради выбора способа работы, повторять весь запрос, показывать внутреннее имя папки или выдавать несколько уведомлений для совместимых навыков.
