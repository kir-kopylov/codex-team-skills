# Хороший Пример: Новый Workflow

## Вход

Пользователь пишет: “У нас появился повторяемый workflow для подготовки коротких отчётов по встречам. Сделай из этого командный skill, чтобы коллеги запускали его обычной фразой.”

## Ожидаемое Поведение

Codex уточняет только недостающие элементы: повторяемую задачу, естественные триггеры и границы применения. Затем создаёт skill через `scripts/new_skill.py`, заполняет `SKILL.md`, `skill.yaml`, `known-exceptions.yaml`, 3 good examples и 2 anti-examples, добавляет строку в `catalog.md`, запускает `python3 -m pytest` и сообщает результат.

## Нельзя

Нельзя ограничиться текстом “вот как можно сделать skill” без создания файлов. Нельзя оставлять шаблонные заглушки в `team-ready`. Нельзя добавлять в examples реальные приватные заметки встреч, имена клиентов или raw exception logs.
