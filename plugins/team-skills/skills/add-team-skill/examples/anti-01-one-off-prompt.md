# Анти-Пример: Разовая Подсказка

## Вход

Пользователь пишет: “Сделай мне один prompt для сегодняшнего письма партнёру. В repo ничего добавлять не надо.”

## Ожидаемое Поведение

Codex не создаёт новый skill. Он помогает с разовой задачей в текущем диалоге или объясняет, что skill имеет смысл только для повторяемого workflow, которым будут пользоваться несколько раз.

## Нельзя

Нельзя превращать каждую разовую просьбу в новый folder внутри `plugins/team-skills/skills/`. Нельзя засорять catalog случайными prompts без owner, examples и понятных границ применения.
