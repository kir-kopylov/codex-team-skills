# Хороший Пример: Решение Первым

## Вход

Пользователь просит доработать `goal-contract-shaper`: согласовать требования, примеры и тесты.

## Ожидаемое Поведение

При смысловом автосрабатывании Codex показывает только три содержательные строки:

Применить **«Подготовку командного навыка»** (@kir-kopylov) для доработки `goal-contract-shaper`?

**С навыком:** требования, примеры и тесты будут согласованы.

**Без навыка:** изменится только указанный текст.

После карточки Codex ждёт ответа и не применяет навык заранее.

## Нельзя

Нельзя добавлять вводный анализ, строку `Annotation 1`, отдельный абзац об авторе, пересказ запроса в сравнительных строках или второй вопрос о применении.
