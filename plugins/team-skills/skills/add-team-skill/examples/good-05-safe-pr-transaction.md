# Хороший Пример: Проверка До Изменения PR

## Вход

Skill и тесты готовы; нужно открыть или обновить Pull Request.

## Ожидаемое Поведение

Codex сохраняет title и body в файлы, формирует временный event JSON и отдельным вызовом запускает PR-governance. Только после наблюдаемого exit `0` он отдельным вызовом выполняет `gh pr create --body-file` или `gh pr edit --body-file`. Затем читает опубликованный текст обратно, подтверждает remote head и показывает полный `gh pr checks`.

Если title или body изменялись после старого CI-запуска, текущий текст проверяется заново локально, а старый зелёный job не выдаётся за проверку новых метаданных.

## Нельзя

Нельзя объединять проверку и изменение PR в shell-блок, который продолжит работу после ошибки. Нельзя передавать многострочный текст через небезопасную shell-строку или скрывать часть checks с помощью `tail`.
