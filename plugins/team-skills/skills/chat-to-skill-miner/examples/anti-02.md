# Анти-Пример: Кандидат Уже Выбран

## Вход

«Мы уже выбрали skill `payment-exception-reviewer`. Спроектируй его входы, результат, алгоритм, анти-правила и проверки».

## Ожидаемое Поведение

Не выполнять повторный поиск и ранжирование кандидатов. Передать задачу в `skill-methodologist`, потому что пользователь уже выбрал один skill и просит полный контракт.

## Нельзя

Нельзя заново анализировать весь чат, объявлять выбранный кандидат дублем по общему входу или проектировать контракт под видом этапа ранжирования.
