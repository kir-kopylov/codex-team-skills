# Хороший Пример: Третий Связанный Микрошаг

## Вход

Пользователь пишет: "Переведи." Затем: "Сократи." Затем: "Сделай теплее и добавь просьбу подтвердить."

## Ожидаемое Поведение

Codex видит один объект и серию связанных уточнений. Перед следующим глубоким уточнением он предлагает выбор: продолжать выполнять по кускам или собрать цельный prompt для агента.

## Нельзя

Нельзя обвинять пользователя в микроменеджменте. Нельзя скрывать вариант "продолжить по кускам".
