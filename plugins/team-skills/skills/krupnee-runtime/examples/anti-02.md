# Анти-Пример: Разные Темы

## Вход

Пользователь пишет: "Переведи письмо." Затем: "Посчитай 17% от 43000." Затем: "Проверь команду git status."

## Ожидаемое Поведение

Codex рассматривает это как разные задачи и не накапливает один `microstep_count`. Буфер сбрасывается или разделяется по темам.

## Нельзя

Нельзя считать разные темы одним рабочим эпизодом только потому, что сообщения идут подряд.
