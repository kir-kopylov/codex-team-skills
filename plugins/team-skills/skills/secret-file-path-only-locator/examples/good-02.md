# Хороший Пример: revoke-first очистка

## Вход

«Path-only отчёт нашёл один access token в документе и две его копии в письмах. Зачисти это безопасно».

## Ожидаемое Поведение

Skill не удаляет копии сразу. Сначала назначает владельца revoke/rotate, подтверждает replacement и недействительность старого доступа, затем формирует batch из трёх source pointers. После явного подтверждения удаляет или редактирует только этот batch; versions и trash запрашиваются отдельно. Финал `REMEDIATION_VERIFIED` возможен только после повторного scan того же scope.

## Нельзя

Нельзя удалять до revoke/rotate, передавать значение в чат, считать удаление письма отзывом токена или очищать version history и trash без отдельного подтверждения.
