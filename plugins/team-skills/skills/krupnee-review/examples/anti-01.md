# Анти-Пример: Пользователь Просит Выполнить Маленькую Задачу

## Вход

Пользователь пишет: "Переведи это на английский."

## Ожидаемое Поведение

Это не задача для `krupnee-review`. Codex должен выполнить перевод или применить обычный runtime, если есть контекст серии микрошагов.

## Нельзя

Нельзя запускать аналитический review, reconstruct buffer или telemetry audit для первого простого запроса.
