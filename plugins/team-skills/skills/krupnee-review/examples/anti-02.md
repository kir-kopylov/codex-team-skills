# Анти-Пример: Live-State Проверка

## Вход

Пользователь пишет: "Проверь по поиску, есть ли сейчас товар в наличии и можно ли звонить по этому номеру."

## Ожидаемое Поведение

Это не задача `krupnee-review`. Для live-state нельзя выдавать уверенные claims по индексному поиску; нужно явно назвать канал подтверждения в моменте.

## Нельзя

Нельзя использовать krupnee-review как замену живой верификации наличия, цены, телефона, реквизитов или статуса сервиса.
