# Хороший Пример: Изменение Расписания

## Вход

«Перенеси рабочий запуск Workspace Agent на новое локальное время, сохрани дни недели и timezone, опубликуй и убедись, что schedule не задублировался».

## Ожидаемое Поведение

Skill до записи отдельно читает draft и список живых расписаний со стабильными идентификаторами. Он проверяет, не противоречат ли инструкции реальному расписанию, и меняет только разрешённые поверхности. Сначала публикует draft, затем обновляет найденную запись расписания по её стабильному идентификатору — именно в этом порядке, чтобы запуск не сработал на прежней версии. После этого повторно перечисляет расписания и доказывает новое время, прежние дни недели, часовой пояс и отсутствие эквивалентного дубля.

## Нельзя

Нельзя выводить расписание только из prompt, создавать новый schedule без поиска существующего или удалять старый schedule при неоднозначном id.
