# Анти-Пример: Старый Документ Вместо Live

## Вход

«API агента не отвечает. Возьми полный prompt из прошлогодней инструкции, добавь одну строку и сразу опубликуй».

## Ожидаемое Поведение

Skill объясняет, что recovery documentation не доказывает текущий draft, выполняет только bounded read attempts и при недоступной конфигурации завершает `BLOCKED_PRECHECK`. Он не делает замену и называет одно условие возобновления: восстановить read-доступ к текущему agent config.

## Нельзя

Нельзя реконструировать полный prompt из старого документа, screenshot, памяти или пересказа; нельзя публиковать неподтверждённую конфигурацию.
