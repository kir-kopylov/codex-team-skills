# Хороший Пример: Один Нужный Ресурс

## Вход

«Подготовь ZIP этого навыка. В `SKILL.md` есть обязательная ссылка на `assets/rules.txt`; без правил результат будет неполным».

## Ожидаемое Поведение

Skill открывает `assets/rules.txt`, подтверждает, что он функционально нужен, и переносит его вместе с адаптированным `SKILL.md`. Ссылка остаётся неизменной. Упаковщик проверяет существование файла и создаёт архив ровно с двумя записями внутри одной корневой папки.

## Нельзя

Нельзя переносить всю папку `assets/` без проверки каждого файла. Нельзя удалять ссылку ради прохождения проверки или объявлять отсутствующий ресурс необязательным без evidence.
