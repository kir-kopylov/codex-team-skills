# Хороший Пример: Автономная Инструкция

## Вход

«Выгрузи `production-forensic-auditor` одним файлом для пользователя Claude. В исходной папке есть repo-метаданные, но сам навык работает только по инструкции».

## Ожидаемое Поведение

Skill читает исходный `SKILL.md`, создаёт отдельную временную копию и по смыслу убирает только карточку командного подключения, feedback, exception logging и инструкции доставки repo. Оставшаяся инструкция автономна, поэтому подготовленная папка содержит только `SKILL.md`. Упаковщик создаёт ZIP с корнем `production-forensic-auditor/` и возвращает точный состав, а отчёт содержит `Статус: STATIC_VALIDATED` и `Загрузка в Claude: не выполнялась`.

## Нельзя

Нельзя копировать `LICENSE.txt`, `skill.yaml`, `known-exceptions.yaml`, примеры или README только потому, что они были рядом с исходником. Нельзя изменять исходную папку.
