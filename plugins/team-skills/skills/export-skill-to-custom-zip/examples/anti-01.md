# Анти-Пример: Claude Code

## Вход

«Установи этот командный навык в Claude Code и сделай так, чтобы он обновлялся вместе с библиотекой».

## Ожидаемое Поведение

Skill распознаёт другую целевую поверхность и не строит Custom Skills ZIP. Он направляет пользователя в существующий Claude Code marketplace репозитория и сохраняет текущий delivery-контракт.

## Нельзя

Нельзя подменять marketplace одноразовым ZIP, создавать второй updater или утверждать, что импорт в Claude.ai обновит навык в Claude Code.
