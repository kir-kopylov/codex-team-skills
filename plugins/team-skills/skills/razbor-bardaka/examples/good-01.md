# Хороший Пример: Коллекция Шаблонов В Менеджере Буфера Обмена

## Вход

«У меня в менеджере буфера обмена накопилось ~300 сохранённых промптов в 29 папках с именами вроде "п гл", "з", "пркс" — сам уже не помню, что где. Наведи порядок, чтобы было удобно искать.»

## Ожидаемое Поведение

Skill сначала разведывает: находит хранилище приложения, считает корпус (объекты, папки, типы), проверяет два жёстких ограничения — поддерживает ли приложение вложенные папки и есть ли облачная синхронизация. Затем читает выборку из разных папок и убеждается, что имена папок содержимому не соответствуют. Только после этого задаёт владельцу раунд вопросов: ось поиска, 3 живых объекта («вот это — куда должно лечь?»), судьба дублей, периметр. Строит два варианта структуры (крупный и подробный), раскладывает каждый объект, дубли — в отдельный список без удаления, показывает HTML-карту и текстовый скелет. Явно говорит: «в приложении ничего не тронуто». Перекладка — только после «да», начиная с пробы на одном объекте.

## Нельзя

Писать напрямую в базу приложения с облачной синхронизацией; удалять дубли без просмотренного владельцем списка; классифицировать по именам папок; начинать перекладку до показа карты.
