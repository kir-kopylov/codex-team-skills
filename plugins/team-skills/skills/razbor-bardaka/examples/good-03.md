# Хороший Пример: Повторный Догон Уже Разобранной Коллекции

## Вход

«Мы месяц назад разложили мои заметки по структуре, с тех пор накопилось новое. Обнови порядок.»

## Ожидаемое Поведение

Skill не пересчитывает всё заново: сверяет живой корпус с прошлым `mapping.csv`, находит дельту (новые и удалённые объекты), классифицирует только новое в уже утверждённую структуру, удалённое выкидывает из артефактов, прошлые решения владельца не трогает. Обновляет счётчики, карту и проверочный скрипт, показывает короткий отчёт: «+N новых, −M удалённых, куда легли». Если среди нового есть цепочка почти-одинаковых версий одной заметки — новейшая идёт как основная, ранние в список дублей с пометкой-допущением.

## Нельзя

Переклассифицировать старые объекты «раз уж взялся»; менять утверждённую структуру папок без запроса владельца; удалять исчезнувшие из прошлых списков объекты где-либо, кроме собственных артефактов skill.
