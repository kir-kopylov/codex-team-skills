# Хороший Пример: Папка С Сотнями Накопленных Файлов

## Вход

«В рабочей папке на диске скопилось под тысячу файлов за три года: отчёты, сканы, черновики, скриншоты. Разбери и разложи по папкам, чтобы находить нужное.»

## Ожидаемое Поведение

Skill не копирует гигабайты ради анализа — папка читается на месте. Инвентаризация идёт по лучшему доступному сигналу: текстовые файлы — по содержимому, сканы и бинарники — по типу, метаданным и беглому просмотру, а не только по именам. Дубли вида `отчёт (1).pdf` попадают в отдельный список кандидатов с причинами. Владельцу задаются вопросы с живыми примерами («этот скан договора — куда?»), затем два варианта структуры и карта. После «да» — свежая резервная копия, сверка «ничего не появилось нового с момента анализа», проба перемещения на одном файле и только потом остальные батчами со сверкой.

## Нельзя

Удалять «мусорные» на вид файлы по догадке; выдавать один-единственный «правильный» вариант структуры; переименовывать файлы без отдельного согласования; пропускать резервную копию перед перекладкой.
