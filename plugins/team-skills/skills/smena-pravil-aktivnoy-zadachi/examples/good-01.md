# Отменённое условие не возвращается из очереди

## Вход

«Убери требование получить фото упаковки из текущей работы и продолжения».

В контракте поиска вещи требуется фото упаковки. Состояние хранит следующий шаг «ждать фото», сценарий — вопрос о фото. Существующее продолжение с ID `fixture-search` активно и повторяет требование. В журнале сохранён уже отправленный вопрос. Иных исполнителей у задачи нет.

## Ожидаемое Поведение

Прочитать связанные источники, убрать действующее требование и зависимость следующего шага от ответа. Обновить тот же ID продолжения, сохранив расписание, уведомления и состояние запуска. Исторический вопрос оставить, добавить событие о смене правила в существующий журнал. Перечитать записи и показать ближайший шаг по оставшимся условиям без отправки сообщения.

## Нельзя

Исправить только контракт; удалить исторический вопрос; ждать фото под другим названием; создать вторую автоматизацию; сообщить собеседнику об изменении без поручения.
