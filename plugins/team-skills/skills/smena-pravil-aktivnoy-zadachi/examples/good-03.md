# Новая проверка распространяется на подготовленный черновик

## Вход

«Перед каждой отправкой нужен отдельный просмотр черновика проверяющим. Примени это и к уже подготовленным сообщениям. Саму задачу пока не возобновляй».

Контракт разрешает отправку владельцем диалога. В состоянии уже есть неотправленный черновик со старой отметкой «готов». Существующее продолжение с ID `fixture-followup` приостановлено. Другой исполнитель отсутствует; сам проверяющий ещё не запускался.

## Ожидаемое Поведение

Добавить принятое условие в контракт, снять готовность старого черновика до результата отдельного просмотра и обновить инструкцию существующего продолжения. Сохранить его приостановленным. После повторного чтения показать: ближайшее зависимое действие — проверка черновика; отправка без её результата невозможна по новым правилам. Саму проверку и отправку не запускать ради сверки.

## Нельзя

Оставить старый черновик готовым по прежнему правилу; считать исторический тест новой проверкой; включить продолжение; выполнить предметное действие вместо применения правила.
