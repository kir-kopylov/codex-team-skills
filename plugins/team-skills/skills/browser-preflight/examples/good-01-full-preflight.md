# Пример: полный прогон перед целью

## Вход

Человек: «Вооружи браузер — завтра запускаю цель: купить память на `avito.ru`, вход через `id.vk.com`».

## Ожидаемое Поведение

Агент ведёт сопровождаемый цикл, где судья это страница расширения, а не диск.

1. Инвентаризация: `avito.ru`, `www.avito.ru` и домен входа `id.vk.com`. Если периметр ещё не зафиксирован, один вопрос человеку: «Какие домены в этом списке нужно добавить или убрать?». Про `id.vk.com` отдельное предупреждение: вооружив домен входа навсегда, вы разрешаете агенту действовать на странице вашего аккаунта без спроса; человек подтверждает.
2. Сверка следа: человек открывает страницу расширения → `Permissions` → «Your approved sites» (обновив её). Для скорости агент запускает `check_grants.py` как подсказку — она совпала со страницей: вооружён только `avito.ru`.
3. Проба «кнопка починена?»: человек жмёт `Always allow` на всплывшем окне, домен в списке не появился — значит кнопка всё ещё сломана, идём в обход.
4. Обход: агент проговаривает предупреждение о безопасности (зачем браузер блокирует вставку, что вставлять только понятный код из этого skill), выдаёт снипет с недостающими доменами; человек набирает `allow pasting`, вставляет, получает `ГОТОВО`.
5. Повторная сверка следа: человек обновляет «Your approved sites» — видны все три домена.
6. Проба тишины: агент по очереди инициирует чтение страницы каждого домена и после каждого спрашивает человека «окно всплыло?»; человек отвечает «нет» на все три.
7. Вердикт: «цикл можно отпускать; вооружены 3 из 3, отзыв — кнопкой `Revoke`».

## Нельзя

Нельзя засчитывать грант по факту нажатия кнопки без сверки следа; засчитывать пробу тишины самому агенту (окно живёт в приложении `Claude Code`, агент его не видит); вооружать домен входа в аккаунт без отдельного предупреждения и согласия; выдавать зелёный вердикт, пока хоть один домен не подтверждён человеком на странице.
