# Хороший Пример: Куда Нажать

## Вход

Пользователь прислал скриншот страницы GitHub `Create a new fork` и спрашивает: `куда нажать?`

## Ожидаемое Поведение

Skill отвечает коротко и по текущему экрану:

`Нажмите зеленую кнопку Create fork внизу справа. Оставьте owner и repository name как есть.`

После перехода на fork skill объясняет следующий шаг только после нового состояния экрана: искать кнопку `Contribute` или `Compare & pull request`.

Если пользователь уже на странице сравнения, skill проверяет base/head:

- base: исходный repo и `main`;
- head: fork пользователя и ветка с изменениями.

## Нельзя

Нельзя отвечать длинной теорией про git, когда человеку нужен один клик. Нельзя советовать нажимать `Code`, `Star`, `Sync fork` или менять имя repo без причины.
