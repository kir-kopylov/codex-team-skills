# Хороший Пример: Пользовательская Коррекция

## Вход

Пользователь вставляет очищенную карточку ошибки: skill подготовил объявление о самовывозе и написал, что отдаётся кровать, хотя пользователь отдавал только матрас. В карточке есть поля `intended_action`, `actual_action`, `false_assumption`, `user_correction` и `next_time_rule`.

## Ожидаемое Поведение

Codex применяет `skill-exception-reviewer`: отделяет видимое на фото от предмета передачи, помечает сбой как дорогой, потому что он создаёт ложные ожидания у получателя, и предлагает patch proposal. В proposal есть запись для `known-exceptions.yaml` с правилом "если на фото есть сопутствующие предметы, явно писать, что отдаётся только X", правка к `SKILL.md`, anti-example про лишний предмет в объявлении и regression test idea для preflight.

## Нельзя

Нельзя вставлять в repo полный сырой лог переписки, адрес, телефон, имена или приватные фото. Нельзя сразу применять patch без human approval.
