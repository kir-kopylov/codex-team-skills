# Дозаливка нового кластера

## Вход

«Добавь в существующее ядро новый кластер из 4 адресов» — книга `core.xlsx` от прошлого прогона уже есть, в ней ручные вердикты и решения по минусам.

## Ожидаемое Поведение

Прочитать пороги и region_id из существующей книги, не переспрашивать рамки. Гео-проверить один новый кластер, сгенерировать маски только для него, снять частоты только по новым маскам. Дозалить через `semantika.py merge --into core.xlsx`: скрипт сам делает бэкап, добавляет только новые строки и не трогает колонки Вердикт/Решение/Комментарий. Доложить, сколько строк добавлено и где бэкап.

## Нельзя

Пересобирать книгу через `build --force` (затирает ручные правки); повторно снимать частоты по старым маскам; менять существующие вердикты и решения.
