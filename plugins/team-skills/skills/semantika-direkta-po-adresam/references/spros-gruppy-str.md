# Веер Групп Спроса STR (ориентир, не шаблон)

Группы выводятся из бизнеса и локаций конкретного города. Половина групп может быть мёртвой для конкретного случая — не заполняйте группу «для полноты», заполняйте под реальный спрос. Имя группы пишется в поле `group` маски; группы с префиксом «гео» скрипт раскладывает в кампанию «Гео» (1 группа объявлений = 1 кластер).

| Группа (`group`) | Что покрывает | Заметки |
|---|---|---|
| `ядро` | горячий транзакционный спрос уровня города и без гео: снять/аренда/бронь × квартира/жильё/апартаменты × посуточно/на сутки/суточно/краткосрочно | словоформы Вордстат склеивает сам — не плодить падежи |
| `гео` | район, метро, вокзалы, крупные ориентиры рядом с кластерами адресов | спрос живёт на районе и ориентире; точечные улицы — кандидаты, решает частота |
| `гео-вузы-больницы` | «рядом с <вуз>», «рядом с <больница>», абитуриенты и родственники пациентов | только объекты в реальной пешей доступности кластеров |
| `типы` | 1-комн/2-комн/студия + разговорные однушка/двушка/трёшка; атрибуты (парковка, джакузи) | атрибутные — только если продукт реально есть |
| `сроки` | на ночь, на выходные, на 2–5 дней, на неделю | «на ночь» — суточный спрос, не почасовой; почасовую режут минусы «час/почасно» |
| `цена` | недорого, дёшево, цены, сколько стоит | инфо-запросы — пониженная ставка, не минусовать «недорого» |
| `собственник` | от собственника, без посредников, без комиссии, от хозяина | обход агрегаторов |
| `b2b` | командировочные, отчётные/закрывающие документы, юрлица, безнал | конверсия выше среднего |
| `семьи` | для двоих, для семьи, с детьми, с животными | |
| `события` | городские события с приезжим трафиком, праздники, даты | сезонное включение по календарю; проверить событие веб-поиском, не по памяти |
