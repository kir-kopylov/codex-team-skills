# Хороший Пример: В Чате Уже Есть Переговоры Пользователя

## Вход

«Проверь продавцов процессора из моей очереди — я вчера сам кому-то из них уже писал, не помню кому.»

## Ожидаемое Поведение

Перед каждым сообщением skill открывает чат и читает историю. У двух продавцов обнаруживается вчерашняя переписка пользователя: один ответил «Да, ещё продаю», второй — «цена такая-то, без торга». Skill не отправляет туда ни одного сообщения: содержательные ответы живых продавцов засчитываются как пройденный чек-2 с датой-временем из чата, лоты попадают в топ, лимит диалогов не тратится. Шаблон уходит только продавцам с пустыми чатами. В журнале у зачтённых лотов указано: «переписка пользователя, агент не вмешивался».

## Нельзя

Нельзя слать «Здравствуйте! Объявление действующее?» в чат, где продавец уже подтвердил цену и условия — это ломает живые переговоры пользователя; нельзя списывать такие лоты из лимита; нельзя продолжать переговоры от имени пользователя.
