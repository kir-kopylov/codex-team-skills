# Marketplace Lot Verifier

## Согласие На Запуск

Явный вызов — slash-команда, имя skill или первая фраза из каталога — выполняйте сразу, без вопроса. При автосрабатывании на смысловое сходство сначала спросите одной строкой: «Задача похожа на экспериментальный team skill `marketplace-lot-verifier` от `@kir-kopylov` — проверяет б/у-лоты на маркетплейсе диалогами с продавцами и сдаёт топ-N верифицированных. Применить или решить без него?» — и ждите ответа. При отказе выйдите из skill молча: решите задачу с нуля и больше не упоминайте skill.

## Обзор

Skill превращает «найди мне Х на Авито» в проверяемый результат: список лотов, по каждому из которых есть два независимых подтверждения — страница объявления прошла формальную проверку, а живой продавец ответил по существу. Всё остальное честно раскладывается в «отбраковано с причиной» и «без ответа».

Ключевой режим: агент — разведчик, не покупатель. Он пишет продавцам строго по шаблону с аккаунта пользователя, фиксирует ответы и цены, но никогда не договаривается, не бронирует и не называет цену. Покупает пользователь сам.

## Естественные Входы

- «найди и проверь лоты на Авито под конкретную вещь»;
- «кто из продавцов реально продаёт, а не висит мёртвым объявлением»;
- «собери топ-3 живых варианта с ценами и доставкой»;
- «напиши продавцам и узнай, актуально ли»;
- «отсей фейки и серверный хлам, мне нужна обычная планка/карта/телефон».

## Обязательные Входы

1. Точная спецификация вещи и список её ловушек-двойников (что маскируется под неё).
2. Город получения.
3. Залогиненный аккаунт площадки (проверяется наблюдением, не словом).
4. Лимит продавцов и стоп-правила (успех N лотов / исчерпание / срок / ручной стоп).

Нет спецификации или стопов — сначала выяснить (это гейт, а не пожелание). Дефолты при молчании пользователя: волны по 5 продавцов, таймер ответа 12 часов, проверка входящих каждые 2–3 часа, отчёт топ-3.

## Жёсткие Правила

1. **Две ступени, обе обязательны.** Чек-1 (страница): объявление активно (не «зарезервировано», не «забронировано», не «продал» в тексте); цена не ниже порога от медианы; продавец с нормальным рейтингом и историей; фото нестоковые; описание не противоречит спецификации; момент проверки зафиксирован. Чек-2 (диалог): получен содержательный ответ человека на «Объявление действующее? Вы продаёте (позицию)?» и любой ответ на «Подскажите, торг уместен?».
2. **Медиана — один раз.** После сбора всех кандидатов, до первой волны; в журнал числом с датой-временем. Порог «подозрительно дёшево» — 60% медианы. Поздние лоты сверяются с той же медианой, без пересчёта.
3. **Читать чат перед отправкой.** Если в чате есть переписка пользователя — не вмешиваться; содержательные ответы продавца в ней засчитываются как чек-2, лот не тратит лимит.
4. **Строго шаблон.** Никаких самодеятельных вопросов. Разрешённое расширение: точное имя позиции или партномер внутри шаблона и третий фиксированный вопрос про спецификацию, если фото не читается. Встречный вопрос продавца → «Уточню и вернусь.» + запись в журнал.
5. **Человек, не автоответчик.** Мгновенные заготовки («отвечу позже») не в зачёт и таймер не сбрасывают. В журнале провенанс каждого ответа: человек / автоответчик / нет ответа.
6. **Спецификация — по прямому признаку.** Заголовок не доказательство. Партномер с фото (зум) или из характеристик карточки; сомнение = третий вопрос; нет подтверждения = «НЕ ПОДТВЕРЖДЁН», в топ не идёт.
7. **Журнал — единственный источник правды.** Только дописывается; все цифры отчёта берутся из него. Тайминг значимых действий фиксируется с точностью до минуты.
8. **Любая преграда = стоп.** Капча, разлогин, блокировка, зависший инструмент — записать в журнал, позвать пользователя одной строкой (что случилось + одно точное действие), ждать. Не обходить. Дважды ошибся в догадке об одном и том же — стоп, а не третья теория.

## Запрещено

- Покупать, бронировать, резервировать, называть цену, обещать, торговаться.
- Отправлять шаблон в чат, где пользователь уже ведёт переговоры.
- Засчитывать «пришло любое сообщение» как подтверждение.
- Менять медиану задним числом или пересчитывать под новые лоты.
- Продолжать рассылку после выполнения стоп-условия успеха.

## Процесс

1. **Гейт входов**: спецификация + ловушки, город, стопы; вход в аккаунт подтверждён наблюдением (виден профиль пользователя).
2. **Сбор кандидатов**: поиск по каналам, отсев двойников по названию и описанию; фиксация улова в журнале (цена, продавец, рейтинг, особенности).
3. **Медиана и очередь**: медиана один раз → порог → единая очередь по выгодности (цена + доставка до города).
4. **Фаза 0 — сквозная проба**: один лучший чистый кандидат через весь путь (чек-1 со скриншотом → открыть чат → убедиться, что пуст → два шаблонных сообщения → журнал). Блокер здесь = стоп и доклад, волны не стартуют.
5. **Волна**: до 5 продавцов на позицию; перед каждым — чтение чата; проверка входящих каждые 2–3 часа; молчание дольше таймера → статус «без ответа», место занимает следующий из очереди.
6. **Финал по стоп-правилу**: отчёт топ-N таблицей (цена, доставка, полная стоимость, город, проверка при получении, торг, рейтинг и стаж продавца, дата-время подтверждения) + отбракованные с причинами + «без ответа» отдельным списком + полный журнал переписки. Дубль отчёта в чат.

Механика конкретной площадки (Авито): маршруты, статусы объявлений, приёмы работы с чатом и известные грабли — в `references/domain-playbook.md`.

## Проверки Перед Сдачей

1. У каждого лота топ-N — обе ступени с датой-временем и провенансом «человек».
2. Каждое отправленное сообщение есть в журнале; счётчик лимита сходится с журналом.
3. Спецификация каждого финалиста подтверждена прямым признаком, а не заголовком.
4. Отклонения от контракта (недоступные скриншоты, исключённые каналы) названы в отчёте явно, не замолчаны.

## Границы

Не использовать для: самой покупки или бронирования (запрещено безусловно); розницы без диалогов (там проверка наличия на сайте — другой процесс); разовой справки о ценах; торга и переговоров от имени пользователя; площадок, где у пользователя нет аккаунта.

## Definition Of Done

Пользователь получил отчёт, в котором каждый лот топ-N подтверждён страницей и живым ответом продавца с датой-временем, отбраковка объяснена, журнал полон, а решение о покупке осталось за пользователем.
