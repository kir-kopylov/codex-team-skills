# Хороший Пример: Telegram Offline При Включённом VPN

## Вход

Пользователь пишет: "Telegram на Windows не может подключиться. Happ/VPN включён, браузер открывает сайты, а Telegram ведёт себя так, будто интернета нет. Я хочу, чтобы Telegram работал именно при включённом VPN."

## Ожидаемое Поведение

Skill фиксирует целевое приложение, заявленный финал и прямое доказательство: свежий скрин Telegram Desktop с реально загруженными чатами или подтверждение пользователя после успешной авторизации. Он не считает форму входа, spinner, процесс Telegram или успешный `curl` доказательством.

Дальше skill строит layer matrix: user-visible UI Telegram, настройки proxy в Telegram, процесс/сокеты, Windows proxy, DNS/fakeDNS, routes/TUN, VPN core и внешняя доступность. Следующий ход формулируется как один эксперимент: например переключить Telegram с "system proxy" на "no proxy" или наоборот только после свежего скрина настроек и записи state fingerprint.

## Нельзя

Нельзя говорить "VPN работает, значит Telegram должен работать". Нельзя закрывать цель по экрану входа или по проверке из PowerShell, потому что это не доказывает сетевую реальность Telegram Desktop.
