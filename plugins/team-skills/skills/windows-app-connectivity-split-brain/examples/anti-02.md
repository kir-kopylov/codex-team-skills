# Анти-Пример: Не Тот Skill

## Вход

Пользователь пишет: "`git pull`, `curl` и `pip` не видят интернет, но Chrome открывает сайты. Конкретное GUI-приложение не упоминается".

## Ожидаемое Поведение

Этот skill не должен захватывать задачу как основную. Нужно передать случай в `vpn-terminal-doctor`, потому что симптом находится в терминальном слое при живом браузере.

Если позже появится конкретное GUI-приложение с отдельным offline-поведением, можно вернуться к `windows-app-connectivity-split-brain`.

## Нельзя

Нельзя раздувать skill до общей починки Windows networking. Нельзя чинить Store, `git`, `pip` или весь VPN-провайдер через этот route, если проблема не про конкретное Windows GUI-приложение.
