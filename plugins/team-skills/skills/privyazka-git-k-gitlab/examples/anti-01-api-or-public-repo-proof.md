# Анти-Пример: API Или Публичный Repo Как Ложное Доказательство

## Вход

«У токена только `read_repository` и `write_repository`. Проверь, рабочий ли он, но приватный repo я не указываю».

## Ожидаемое Поведение

Skill проверяет локальное сохранение через GCM и честно завершает на `LOCAL_CREDENTIAL_READY`. Он объясняет одной строкой: без приватного доступного repo server-side Git-проверки сейчас нет.

## Нельзя

Нельзя вызывать `/api/v4/user`: repository scopes не являются API scopes. Нельзя использовать публичный repo: анонимный доступ даст ложноположительный результат даже с неверным токеном.
