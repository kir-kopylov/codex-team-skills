# Хороший Пример: Проверка На Приватном Репозитории

## Вход

«Локальное сохранение готово. Вот точный HTTPS URL моего приватного проекта; проверь чтение, но ничего не клонируй и не пушь».

## Ожидаемое Поведение

Skill использует ровно переданный URL и выполняет только `git ls-remote <точный-url> HEAD`. При успехе выдаёт `REMOTE_READ_VERIFIED`. Он отдельно пишет, что право push не проверено, потому что пользователь запретил запись и scope сам по себе не доказывает server-side доступ.

## Нельзя

Нельзя менять remote, клонировать проект, делать тестовый commit/push, подставлять token в URL или заменять приватный URL похожим публичным проектом.
