# Хороший Пример: Замена Старого Credential

## Вход

«Я создал новый PAT, но Git продолжает использовать старый токен. В Windows уже есть запись для GitLab».

## Ожидаемое Поведение

Skill сначала фиксирует факт старой локальной записи, не создаёт ещё один PAT без причины и запускает bundled script с `-Replace -HostWide`. Пользователь вводит новый token только в скрытом PowerShell prompt. После `LOCAL_CREDENTIAL_READY` skill сообщает, что старая host-level запись заменена локально; серверная проверка остаётся отдельным необязательным шагом.

## Нельзя

Нельзя печатать содержимое credential через `git credential fill`, просить token сообщением, удалять все Windows credentials или объявлять remote access подтверждённым по одному `cmdkey /list`.
