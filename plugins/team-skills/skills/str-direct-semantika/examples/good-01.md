# Полный цикл: новый город

## Вход

«Собери семантику для Директа: посуточные квартиры, Город N, вот 12 адресов» — далее список адресов и рамки «только квартиры, без почасовой».

## Ожидаемое Поведение

Спросить только недостающее (по одному вопросу). Сгруппировать адреса в кластеры по улицам без агентов; гео-проверить по одной на кластер. Сгенерировать маски по вееру групп, собрать config, построить книгу. Собрать частоты через браузер пользователя с журналом `wordstat-progress.jsonl`; проставить вердикты по порогам (или пометить пороги `[requires recheck]` и откалибровать на этом прогоне). Прогнать `minus-check`, разобрать хвосты, отдать книгу с непустым листом «Кампании».

## Нельзя

Проверять гео по каждому адресу отдельно; выбрасывать маски «по типу» без частоты; выдумывать частоты; заливать минус-лист без проверки на самоконфликты; обходить капчу.
