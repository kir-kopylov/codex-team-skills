# Хороший Пример

## Вход

Пользователь пишет: "Windows не видит интернет, Store ругается, но браузер и curl открывают сайты. `dns.msftncsi.com` почему-то возвращает `198.18.1.205`."

## Ожидаемое Поведение

Сначала собрать статус без изменений: `Get-NetConnectionProfile`, NCSI registry, DNS probe и HTTP probe. Затем сравнить `ActiveDnsProbeContent` с фактическим DNS-ответом. Если Windows ожидает `131.107.255.255`, а текущая сеть стабильно возвращает `198.18.1.205`, объяснить fake-IP как сетевую политику, сделать backup NCSI, временно выставить `ActiveDnsProbeContent=198.18.1.205`, очистить DNS cache, перезапустить минимальный набор служб и проверить `IPv4Connectivity : Internet`.

## Нельзя

Сразу отключать VPN, сбрасывать TCP/IP, удалять TAP-драйверы, менять DNS-серверы или объявлять `198.18.x.x` поломкой без сравнения NCSI expectation vs фактический DNS.
