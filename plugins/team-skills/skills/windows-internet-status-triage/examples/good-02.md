# Хороший Пример

## Вход

Пользователь пишет: "Мы убрали fake-IP на роутере, и Windows снова показывает без интернета. Раньше NCSI был временно поставлен на `198.18.1.205`."

## Ожидаемое Поведение

Проверить текущий DNS-ответ `dns.msftncsi.com` и текущее `ActiveDnsProbeContent`. Если DNS снова возвращает стандартный Microsoft-ответ, а Windows ожидает старый fake-IP, восстановить backup `.reg` или вернуть `ActiveDnsProbeContent` к `131.107.255.255`. После этого очистить DNS cache, перезапустить `NlaSvc`/`netprofm`, проверить `Get-NetConnectionProfile`.

## Нельзя

Поддерживать старый workaround после изменения сетевой политики. Нельзя говорить, что "интернет пропал": проблема в устаревшей настройке проверки Windows.
