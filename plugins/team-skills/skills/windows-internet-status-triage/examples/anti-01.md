# Анти-Пример

## Вход

Пользователь пишет: "Windows без интернета, что делать?"

## Неправильное Поведение

Ассистент сразу запускает `Set-ItemProperty` для `ActiveDnsProbeContent`, перезапускает службы и говорит, что проблема решена.

## Почему Это Плохо

Не доказано, что сеть жива. Не проверены DNS, HTTP probe, текущая NCSI expectation и фактический ответ. Нет backup. Такая правка может скрыть настоящую сетевую поломку или сломать статус после смены DNS-политики.

## Правильно

Сначала `collect-network-status`, затем классификация: реальная сеть мертва, Windows status неверный или проблема только приложения.
