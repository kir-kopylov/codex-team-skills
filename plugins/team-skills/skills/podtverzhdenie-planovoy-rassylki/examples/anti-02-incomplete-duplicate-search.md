# Анти-пример: неполный поиск дублей

## Вход

Одна копия найдена, но поиск смотрел только Inbox, не прошёл все страницы и не содержит правила, какие варианты темы считать тем же выпуском.

## Ожидаемое Поведение

Skill возвращает `UNPROVEN` для части про дубли и называет границу: Inbox и неполный список. Наличие одной копии само по себе не доказывает отсутствие второй.

## Нельзя

Не писать «дублей нет» без полного поиска в объявленной области и не расширять вывод на архив, Sent или другие ящики.
