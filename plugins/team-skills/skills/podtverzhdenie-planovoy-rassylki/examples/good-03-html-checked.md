# Хороший пример: HTML — часть выпуска

## Вход

Запись отправки и полученная копия совпадают по теме и тексту, но ожидаемый HTML содержит ссылку A, а полученный HTML — ссылку B.

## Ожидаемое Поведение

Skill возвращает `FAIL` с причиной «HTML не совпал». Это не компенсируется тем, что текст письма выглядит верным.

## Нельзя

Не считать HTML декоративным, если он входил в зафиксированный ожидаемый выпуск.
