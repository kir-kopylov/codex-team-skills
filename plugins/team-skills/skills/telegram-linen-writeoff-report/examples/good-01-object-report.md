# Отчет По Объектам

## Вход

Пользователь пишет: "Сделай отчет списания белья по Telegram export за период
с 2026-05-01 по 2026-05-31. Экспорт лежит в папке, там есть `messages.html`."

## Ожидаемое Поведение

Codex находит `messages.html`, проверяет явный период и доступность ожидаемых
`scripts/` и `references/`. Если пакет доступен, Codex читает правила подсчета и
aliases, запускает `scripts/build_linen_report.py` с inclusive start/end и
возвращает отчет в chat по объектам. В конце он добавляет totals и блок
`Спорные или непонятные места`, если были подписи к фото, дубли или неясные
объекты.

## Нельзя

Нельзя считать вручную по отдельным фрагментам чата, игнорировать
`references/linen_rules.md`, объединять `МП` с `НП` или скрывать спорные строки.
