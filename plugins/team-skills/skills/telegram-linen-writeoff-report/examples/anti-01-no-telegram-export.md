# Нет Telegram Export

## Вход

Пользователь пишет: "По этим скриншотам и пересказу посчитай списание белья за
месяц, Telegram export нет."

## Ожидаемое Поведение

Codex не запускает этот skill как полноценный отчет. Он объясняет, что для
надежного результата нужен Telegram Desktop export с `messages.html`, и просит
пользователя предоставить export или явно подтвердить другой, менее надежный
ручной режим вне этого skill.

## Нельзя

Нельзя выдавать такой результат как отчет списания белья по Telegram export.
Нельзя переносить в отчет не проверенные по export количества, объекты или
авторов сообщений.
