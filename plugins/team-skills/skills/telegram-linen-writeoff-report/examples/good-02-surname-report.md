# Отчет По Фамилиям

## Вход

Пользователь пишет: "Сделай отчет по белью по фамилиям за 2026-04-15 -
2026-05-14 из Telegram export."

## Ожидаемое Поведение

Codex подтверждает наличие `messages.html`, проверяет ожидаемые scripts и
references, затем запускает report builder в режиме группировки по фамилиям
отправителей. Если фамилия не извлекается надежно, Codex не придумывает ее, а
выносит запись в спорные места или в предусмотренную скриптом группу.

## Нельзя

Нельзя группировать по фамилиям на основе догадок, аватарок, неявных ников или
прошлой памяти о чате. Нельзя продолжать без resource gate, если ожидаемый
скрипт или правила недоступны.
