# Хороший Пример: Изменение Расписания

## Вход

«Перенеси рабочий запуск Workspace Agent на новое локальное время, сохрани дни недели и timezone, опубликуй и убедись, что schedule не задублировался».

## Ожидаемое Поведение

Skill до записи отдельно читает draft и список live schedules со stable ids. Он проверяет, не противоречат ли instructions реальному cadence, изменяет только разрешённые поверхности, публикует draft, повторно перечисляет schedules и доказывает новое время, прежние дни, timezone и отсутствие эквивалентного дубля.

## Нельзя

Нельзя выводить расписание только из prompt, создавать новый schedule без поиска существующего или удалять старый schedule при неоднозначном id.
