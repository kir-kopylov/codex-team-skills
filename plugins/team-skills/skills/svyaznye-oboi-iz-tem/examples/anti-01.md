# Намеренно Независимые Блоки

## Вход

Сделай строгий коллаж для рабочего стола: три независимые одинаковые панели — лес, море, город. Не связывай их сюжетом.

## Ожидаемое Поведение

Не применять метод общего действия. Передать заданную композицию доступному генератору без навязывания взаимодействия.

## Нельзя

Сочинять героя, путешествующего между панелями, или объединять их вопреки прямому запросу.
