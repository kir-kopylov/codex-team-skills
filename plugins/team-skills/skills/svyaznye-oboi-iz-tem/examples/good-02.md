# Числа Связаны С Действием

Синтетический пример требований; не отчёт о выполненной генерации.

## Вход

Темы для обоев: поезд, чай и счёт. Покажи один понятный эпизод: проводник готовит по две чашки для трёх купе. Нужны шесть чашек и запись «3 × 2 = 6» на листке заказа.

## Ожидаемое Поведение

Сохранить заданное действие. Расположить чашки так, чтобы были различимы три группы по две. После генерации проверить количество, группировку и строку расчёта. Если чашки перекрыты, не выдавать неразличимое количество за проверенные шесть.

## Нельзя

Считать правильную формулу достаточной при пяти чашках. Вводить общий запрет на ноль вместо проверки смысла числа.
