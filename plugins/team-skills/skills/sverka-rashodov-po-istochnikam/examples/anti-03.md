# Исторический отчёт при поздней правке заявки

## Вход

Это вся выручка после комиссии на 20 июня? Текущая запись eHous изменена 22 июня. Датированной выгрузки нет. В настройке ставка записана дробью, её единицы не подтверждены. Приложена выписка по другой заявке.

## Ожидаемое Поведение

Сохранить текущие поля и отметить, какие значения на 20 июня не подтверждены. Для изменённой заявки оставить зависимое начисление на дату неизвестным, пока нужные поля не восстановлены по датированным источникам. Вывести подтверждённое по доступным документам отдельно с их охватом. Дробь из настройки оставить исходным значением, требующим проверки.

## Нельзя

Считать текущую строку снимком на прошлую дату, применять ставку по виду числа, подставлять выписку другой заявки или выдавать совпавшее подмножество за весь доход.
