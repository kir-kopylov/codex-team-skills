# Хороший Пример: Remote И Установленный Plugin Различаются

## Вход

«Почему новый навык уже есть в GitHub, но я не вижу его в Codex?»

## Ожидаемое Поведение

Codex читает remote SHA и manifest из одного commit, затем отдельно получает JSON текущей CLI. Удалённый `main` содержит skill и более новую semver, а установленный plugin наблюдаемо остался на прежней semver и не содержит каталог skill. Marketplace ref неизвестен, текущая сессия также не показывает имя.

Итог: конечные состояния remote и установленного plugin наблюдаемо различаются, но первое соседнее расхождение и граница доставки не локализованы из-за неизвестного marketplace. Диагностика ничего не обновляет.

## Нельзя

Нельзя сразу запускать upgrade, называть remote и установленный plugin соседними слоями или утверждать, почему marketplace не обновился, если его конкретный snapshot не наблюдаем.
