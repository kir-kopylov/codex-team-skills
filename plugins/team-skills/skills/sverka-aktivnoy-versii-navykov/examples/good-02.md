# Хороший Пример: Одноимённая Личная Копия

## Вход

«Проверь, не перекрывает ли мой локальный skill командный».

## Ожидаемое Поведение

В проверенном личном корне найден обычный каталог, у которого имя папки и frontmatter `name` точно совпадают с именем skill установленного plugin. Текущая сессия показывает имя skill, но не раскрывает путь его источника.

Итог для личного слоя — `POTENTIAL_PERSONAL_SHADOW`, а не доказанное перекрытие. Для `OBSERVED_PERSONAL_SHADOW` не хватает наблюдаемого источника загруженного skill.

## Нельзя

Нельзя перемещать каталог, раскрывать личный путь или объявлять совпадение причиной без данных о приоритете загрузки.
