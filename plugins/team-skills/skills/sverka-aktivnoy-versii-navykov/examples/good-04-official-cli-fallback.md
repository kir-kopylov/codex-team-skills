# Хороший Пример: Сломанный Запуск Из PATH И Проверка CLI Приложения

## Вход

Синтетический сценарий: «Проверь, какая версия командных навыков установлена».
Команда `codex --version` из `PATH` завершается ошибкой `ENOENT` ещё до запуска
CLI. Официальное приложение уже установлено на этой машине; целевой Codex
home/profile установлен из доступных локальных данных.

## Ожидаемое Поведение

Codex фиксирует неудачу конкретного запуска и применяет read-only часть
[общей предварительной проверки](../../obnovlenie-biblioteki-navykov/references/codex-cli-preflight.md).
Он проверяет безопасно обнаруженный официальный binary приложения с тем же
Codex home/profile, без скачивания или изменения настроек.

В положительной ветке `--version` и `plugin --help` выполняются успешно,
а `plugin list --json` возвращает корректную запись установленного
`team-skills@codex-team-skills`. Версия подтверждается этим ответом;
`installedPath` и точный commit marketplace не возвращены и получают
`UNKNOWN_NOT_EXPOSED`. Чтение предполагаемого cache-пути не подменяет эти поля.
Список навыков сессии проверяется отдельно.

В граничной ветке ни один безопасно обнаруженный официальный кандидат для
того же home/profile не запускает нужную команду или не даёт разбираемый JSON.
Marketplace и установленный plugin получают `UNKNOWN_COMMAND_FAILED`.
Codex называет оба проверенных способа запуска и их ошибки, не объявляет
plugin отсутствующим и продолжает независимо проверять доступные remote,
личные кандидаты и данные текущей сессии. Недоказанное совпадение home/profile
также не позволяет использовать ответ другого окружения.

В обеих ветках результат содержит строку «Изменения среды: не выполнялись».

## Нельзя

- Объявлять всю CLI недоступной после одной ошибки запуска из `PATH`.
- Пробовать произвольный исполняемый файл без проверки его происхождения.
- Менять Codex home/profile и выдавать другую установку за целевую.
- Скачивать CLI, править `PATH`, выполнять `plugin add/remove` или
  `marketplace add/upgrade/remove` ради диагностики и обнаружения пути.
- Считать отсутствие поля `installedPath` или ошибку CLI статусом `NOT_INSTALLED`.
