# Хороший Пример: Сессия Не Раскрывает Версию

## Вход

«Какая версия библиотеки навыков реально активна?»

## Ожидаемое Поведение

Remote и установленный plugin наблюдаемы и совпадают по semver. Текущая сессия показывает контрольное имя skill, но не возвращает semver или source загруженного пакета.

Codex подтверждает установленную semver и видимость имени раздельно. Semver текущей сессии остаётся `UNKNOWN_NOT_EXPOSED`; ответ не превращается в более сильное «эта semver активна в сессии».

## Нельзя

Нельзя переносить версию с дискового manifest на runtime только потому, что имя skill видно.
