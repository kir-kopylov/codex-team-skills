# Пример: runtime отсутствует

## Вход

Контракт подтверждён, но команда `goalrt` и runtime skill не найдены.

## Ожидаемое Поведение

Skill выдаёт проверенный текст `/goal` и прямо пишет, что permissions, budgets,
retries, recovery и approval остаются текстовыми условиями под надзором
пользователя. Отсутствие runtime не обнуляет работу shaping.

## Нельзя

Нельзя придумывать `goal-contract.json`, обещать автоматическую остановку или
заставлять пользователя устанавливать runtime, если ему достаточно текста.
