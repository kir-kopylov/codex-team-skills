# Хороший Пример: Планка Памяти С Ловушками-Двойниками

## Вход

«Найди и проверь на Авито планку памяти 16 ГБ DDR4-2400 для обычного ПК — одну, не комплект. Город Екатеринбург, покупать буду сам. Хватит трёх живых лотов.»

## Ожидаемое Поведение

Skill уточняет спецификацию до проверяемой (один модуль, настольная, без серверной коррекции ошибок, не ноутбучная) и называет ловушки-двойники: комплекты 2×8, ноутбучные планки, серверные Registered/ECC, планки с «серверными» буквами в партномере. Собирает кандидатов, фиксирует медиану один раз числом с датой-временем, строит очередь по полной стоимости. Лот за треть медианы с наклейкой «SERVER ONLY REG-ECC» на фото отбраковывает по зуму наклейки без траты диалога. По очереди ведёт диалоги строго по шаблону, засчитывает только содержательные ответы людей и сдаёт отчёт: топ-3 таблицей с датой-временем подтверждений, отбраковка с причинами, журнал переписки.

## Нельзя

Нельзя засчитывать лот по заголовку «16GB DDR4 2400» без прямого признака спецификации; нельзя вести диалог с продавцом заведомо неподходящей планки «на всякий случай»; нельзя пересчитывать медиану под поздние дешёвые лоты.
