# Хороший Пример: Новый Skill Не Дошёл До Установки

## Вход

«Почему новый навык уже есть в GitHub, но я не вижу его в Codex?»

## Ожидаемое Поведение

Codex читает remote SHA и manifest из одного commit, затем отдельно получает JSON текущей CLI. Удалённый `main` содержит skill и более новую semver, а установленный plugin наблюдаемо остался на прежней semver и не содержит каталог skill. Текущая сессия также не показывает имя.

Итог: первое доказанное расхождение — между удалённым `main` и установленным plugin. Это локализует разрыв доставки, но ничего не обновляет.

## Нельзя

Нельзя сразу запускать upgrade или утверждать, почему marketplace не обновился, если его конкретный snapshot не наблюдаем.
