# Анти-Пример: Cache И Checkout Выданы За Реальность

## Вход

«Почему новый навык не виден?»

## Ожидаемое Поведение

Remote `main`, marketplace, установленный plugin и текущая сессия проверяются отдельно. Локальный checkout не доказывает remote SHA, cache не доказывает установленную запись, а файлы на диске не доказывают список навыков уже открытой сессии.

## Нельзя

Нельзя открыть только локальный checkout и свежую папку cache, затем ответить: «новая версия точно установлена и активна».
