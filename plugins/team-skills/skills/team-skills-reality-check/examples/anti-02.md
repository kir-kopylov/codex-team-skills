# Анти-Пример: Диагностика Незаметно Стала Исправлением

## Вход

«Сравни GitHub, установленный plugin и текущую сессию».

## Ожидаемое Поведение

Завершить read-only карту, назвать первое доказанное расхождение и указать, что изменений не было. Исправление — отдельная задача через `team-skills-maintenance`.

## Нельзя

Нельзя после первого несовпадения сразу выполнять marketplace upgrade, plugin add, перенос личной копии и restart: исходное состояние будет потеряно, хотя пользователь просил только отчёт.
