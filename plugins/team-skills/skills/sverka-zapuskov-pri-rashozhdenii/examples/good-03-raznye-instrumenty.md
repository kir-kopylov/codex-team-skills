# Хороший Пример: Разные Инструментальные Пути

## Вход

Два запуска имеют одинаковые запрос, предшествующий контекст, время и модель. Сохранённые журналы показывают: первый запуск вызвал веб-поиск, второй ответил без него. Пользователь спрашивает, подтверждает ли это причину расхождения.

## Ожидаемое Поведение

Гипотезу «инструментальные пути различались» пометить `ПОДТВЕРЖДЕНА` со ссылкой на журналы. Не превращать этот факт автоматически в полную причину смысловой разницы: проверить, является ли наблюдаемое различие ответа следствием найденных источников; при нехватке данных оставить эту связь `НЕ УСТАНОВЛЕНА`.

## Нельзя

Приписывать инструменту всё расхождение только по факту вызова, раскрывать сырой журнал или утверждать внутренний замысел системы.
