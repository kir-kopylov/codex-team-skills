# Анти-Пример: Красивый YAML Выдан За Рабочую Систему

## Вход

«Сделай архитектуру сверки выписок и CRM, чтобы дальше всё считалось автоматически».

## Ожидаемое Поведение

Skill создаёт только проект контракта, помечает ненаблюдавшиеся форматы и возможности внешних систем, проверяет структуру файла и предлагает пилот, который способен опровергнуть проект. В результате прямо указано `production_readiness_claim: false`.

## Нельзя

Нельзя после синтетического примера написать «система готова», обещать чтение любых банковских форматов или считать структурную проверку доказательством полноты реальных данных и правильности управленческого учёта.
