# Хороший Пример: Выписка И Проживание Имеют Разное Зерно

## Вход

«Собери контракт сверки банковской выручки с бронированиями. Одно бронирование может пересекать месяц, сумму надо разнести по суткам проживания».

## Ожидаемое Поведение

Skill не делает одну универсальную строку. В проекте отдельно появляются неизменяемая банковская операция, бронирование CRM, сутки проживания, связь платежа с бронированием и распределение суммы по суткам. У каждого слоя свой идентификатор, а итог месяца ссылается на распределения и исходные записи.

Правило периода остаётся бизнес-правилом «по суткам проживания». Формула распределения и округления помечается как решение, которое должно быть утверждено и испытано на переходе месяца.

## Нельзя

Нельзя считать совпадение суммы достаточной идентичностью, присвоить банковской строке номер бронирования и потерять связь с несколькими сутками или несколькими платежами.
