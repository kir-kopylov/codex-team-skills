# Хороший Пример: Поздний Файл После Закрытия

## Вход

«Еженедельный расчёт уже закрыт, а на следующий день загрузили пропущенную выписку. Как это должно работать?»

## Ожидаемое Поведение

Контракт сохраняет закрытый запуск неизменным, создаёт сигнал позднего входа и переводит период в `REOPEN_REQUIRED`. Уполномоченный человек решает, применяется ли утверждённое правило переоткрытия. Новый расчёт получает новый `run_id`, новый снимок входов и ссылку `supersedes_run_id`; старый результат остаётся доступен для сравнения.

Skill проектирует это поведение, но не открывает период и не запускает расчёт.

## Нельзя

Нельзя незаметно добавить файл в старый запуск, переписать итог и оставить тот же идентификатор: после этого невозможно доказать, какая версия данных породила цифру.
