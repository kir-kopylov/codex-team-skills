# Хороший Пример 2. Идею разобрали и не пересобрали — правила и ADR честно пустые

## Вход

«Мы полдня в этом чате крутили один подход к сервису и в итоге его закопали. Разбери чат и собери выжимку, чтобы в следующей сессии не начинать с нуля.»

## Ожидаемое Поведение

- Фаза 1: карточка доступности первой строкой (последние сообщения дословно, ранний участок сжат), затем `razbor/<дата>-<слаг>/registry.md` на 22 строки-утверждения; строки по сжатому участку помечены `!контекст-сжат`, спорные по статусу — `?` плюс `!сомнение`. Вывод `check_registry.py` вставлен дословно, код возврата 3 — шлюз закрыт, артефакты не собираются, хотя человек просил «выжимку» сразу.
- Человек снял маркеры и выправил первые символы строк; повторный прогон даёт код 0, `sha256` из вывода совпадает с хешем прочитанного файла. Сводка: `+ принято: 0 | x отвергнуто: 12 | ? открыто: 7 | 0 без реакции: 3`. Ноль строк `+` — это результат, а не дефект реестра: статусы не поднимают ради того, чтобы артефактам было чем наполниться.
- `out/rules-delta.md` — ровно одна строка «В этом чате не возникло ничего, чем целесообразно дополнить правила проекта» плюс одно предложение почему: все строки про способ работы отвергнуты (`x`), уцелевшее — открытые вопросы (`?`), а `?` правилом не становится. До пяти строк файл не добивается.
- Папка `out/adr/` пустая: ни одной строки `+`, значит ни одного решения. В ответе сказано прямо: принятых решений ноль; ближе всего к решению была строка 014 — на неё привязаны три альтернативы `x` с `альт:014`, и скрипт вывел по предупреждению на каждую — первое из трёх: `ВНИМАНИЕ: строка 009: альт:014 ссылается на статус ?, а не на +` (код возврата при этом 0). До принятия не хватило подтверждения человеком: строка осталась `?`.
- `out/memory.md`: «Где идея сейчас» — одна строка о том, что чат не дал состояния, подход снят; «Уже отвергнуто, не пересматривать без нового аргумента» — все 12 строк `x` с однострочной причиной по каждой, включая `x` без привязки `альт:`; «Открытые вопросы» — 7 строк `?` без попыток их закрыть. Без хронологии, без «мы обсудили», без атрибуции реплик.
- `out/handoff.md`: цель, состояние на сейчас, раздел решений явно пустой (ни одной `+`), «тупики и почему» — все 12 `x` как антицели, открытое из `?`, один следующий шаг, что прочитать первым, строка возобновления. В конце ответа — список созданных файлов с числом пунктов и номерами строк реестра, затем «Осталось без реакции»: 3 строки `0` отдельным списком, ни в один артефакт не попавшие.

## Нельзя

- Пересобирать разобранную идею самому: предлагать «а вот если сделать иначе» вместо фиксации, что подход закопан. Пункта, которого нет в реестре, в артефактах быть не может.
- Добивать объём: расширять `rules-delta.md` до пяти строк за счёт `x` и `?`, дописывать в память рассуждения из чата ради связности текста.
- Повышать статусы: превращать строку 014 (`?`) в решение, писать по ней ADR, переносить строки `0` в память или передачу смены.
- Заводить ADR ради того, чтобы папка не была пустой: ни ADR по отвергнутой строке, ни «Рассмотренные варианты», собранные из `x` без `альт:` на конкретное решение.
