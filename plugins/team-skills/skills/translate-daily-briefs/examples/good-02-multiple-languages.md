# Хороший Пример: Несколько Языков

## Вход

Пользователь пишет: "Переведи сменный отчет на казахский и узбекский. Сохрани пункты: 1) склад принял 18 коробок, 2) курьер опоздал на 35 минут, 3) возврат по заказу A-104 перенесен на завтра, 4) статус клиента: ждет звонка менеджера".

## Ожидаемое Поведение

Codex использует `translate-daily-briefs`, делает два отдельных блока для казахского и узбекского, сохраняет нумерацию и сверяет 18 коробок, 35 минут, A-104, "завтра" и статус клиента в обоих переводах. Если точная формулировка рабочего статуса требует локального варианта, Codex сохраняет исходный смысл и не добавляет новых деталей.

## Нельзя

Нельзя объединять два языка в один смешанный текст. Нельзя терять пункт про возврат или делать из "ждет звонка менеджера" более сильный статус вроде "менеджер уже позвонит сегодня".
