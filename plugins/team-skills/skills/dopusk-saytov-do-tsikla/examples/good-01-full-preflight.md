# Пример: полный прогон перед целью

## Вход

Человек: «Вооружи браузер — завтра запускаю цель: купить память на `avito.ru`, вход через `id.vk.com`».

## Ожидаемое Поведение

Агент сначала сам наблюдает доступное состояние браузера; сопровождаемый цикл начинается только при доказанном человеческом барьере. Судья — страница расширения, а не диск.

1. Инвентаризация: `avito.ru`, `www.avito.ru` и домен входа `id.vk.com`. Если периметр ещё не зафиксирован, один вопрос человеку: «Какие домены в этом списке нужно добавить или убрать?». Про `id.vk.com` отдельное предупреждение: вооружив домен входа навсегда, вы разрешаете агенту действовать на странице вашего аккаунта без спроса; человек подтверждает.
2. Сверка следа: агент через доступный `Chrome control` обновляет страницу расширения → `Permissions` → «Your approved sites». Для скорости он запускает `check_grants.py` как подсказку — она совпала со страницей: вооружён только `avito.ru`. Пользователь не получает просьбу открыть страницу или пересказать список.
3. Проба «кнопка починена?»: агент доступным инструментом один раз нажимает `Always allow`, затем сам обновляет список. Домен не появился — значит кнопка всё ещё сломана, идём в обход.
4. Обход: агент проговаривает предупреждение о безопасности (зачем браузер блокирует вставку, что вставлять только понятный код из этого skill), выдаёт снипет с недостающими доменами; человек набирает `allow pasting`, вставляет, получает `ГОТОВО`.
5. Повторная сверка следа: агент сам обновляет «Your approved sites» доступным инструментом — видны все три домена.
6. Проба тишины: агент по очереди инициирует чтение страницы каждого домена и сам наблюдает через управление экраном, что окно не всплыло. Пользователь не подтверждает состояние, доступное агенту.
7. Вердикт: «цикл можно отпускать; вооружены 3 из 3, отзыв — кнопкой `Revoke`».

## Нельзя

Нельзя засчитывать грант по факту нажатия кнопки без сверки следа; заранее объявлять окно невидимым агенту без пробы доступными инструментами; просить пользователя пересказывать доступное агенту состояние; вооружать домен входа в аккаунт без отдельного предупреждения и согласия; выдавать зелёный вердикт без наблюдаемого подтверждения каждого домена.
