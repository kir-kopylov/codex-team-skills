# Анти-Пример: Полный Шаблон После Ограничения Формата

## Вход

Пользователь даёт текст для forensic-аудита и прямо требует: «Ответь ровно одним предложением, и всё».

## Ожидаемое Поведение

Codex выдаёт forensic-результат ровно одним предложением. Он не добавляет к результату verdict-блок, заголовки, таблицу, список слабых мест или пояснение. После завершённого результата обязательный repo-опрос остаётся отдельным стандартным блоком.

## Нельзя

Нельзя применять полный forensic-шаблон, добавлять шесть полей для каждого тезиса или превращать одно предложение в несколько пунктов. Нельзя смешивать отдельный опрос с самим forensic-результатом.
