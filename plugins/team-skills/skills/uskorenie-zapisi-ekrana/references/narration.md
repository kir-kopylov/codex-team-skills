# Монтаж речи и экранных событий

Работайте с локальными копиями в отдельной папке. Нужны Python 3.11+, FFmpeg 7+ с libx265 и rubberband-r3. Для автоматической разметки речи используйте Python с пакетом silero-vad и его моделью. Пакет включает веса для автономной работы. Если уже есть доверенная локальная модель Silero TorchScript, достаточно torch и флага `--vad-model ПУТЬ`. При недоступности детектора дайте работать обычной таблице таймкодов. Порог громкости реагирует также на клавиатуру и шум, поэтому он не заменяет детектор речи.

## Разметка

Сначала прочитайте дорожки. Если их несколько, прослушайте образцы: параметр `--audio-track N` выбирает дорожку рассказчика для распознавания и экспорта. Остальные в этот режим не входят. Для записи без дорожки речевая разметка останавливается.

Задайте FRAME_PATTERN шаблоном имён PNG со счётчиком %03d в рабочей папке. EDITED и SMALL — пути к новым MP4. Для поиска визуальных событий получите обзор всего экрана и просмотрите изменения. Затем уточните границы по близким кадрам с читаемым текстом, например на отрывке от 90-й секунды с частотой два кадра в секунду:

```sh
ffmpeg -nostdin -ss 90 -i "$SRC" -t 12 -vf fps=2 -start_number 0 "$FRAME_PATTERN"
```

Нулевой кадр соответствует началу отрывка с точностью до периода выборки. Если нужная граница тоньше, повысьте частоту. Последовательный рост текста в редакторе, индикатор после отправки и постепенное появление ответа дают три разные метки. Вставка готового блока, голосовая расшифровка, мигание каретки и прокрутка готового текста сами по себе их не подтверждают. Защитите произносимые слова при любом пересечении.

В локальный файл `visual.json` запишите полуоткрытые интервалы по часам **исходной** записи. Пример вымышленный:

```json
[
  {"kind":"keyboard","start":10,"end":16,"evidence":"В фокусе поле запроса, последовательно допечатываются буквы с видимым исправлением."},
  {"kind":"wait","start":18,"end":28,"evidence":"После отправки виден индикатор обработки, основная область ответа пуста."},
  {"kind":"answer","start":28,"end":36,"evidence":"В области ответа прибавляются строки, после них появляются кнопки готового сообщения."}
]
```

Если для категории нет подтверждённых кадров, оставьте её без меток и сообщите это при выдаче. Для голосового монтажа без визуальных правил опустите файл и три соответствующих множителя. Скорости в примере замените принятыми в форме значениями:

```sh
python3 scripts/narration.py plan --src "$SRC" --out "$WORK/plan.json" \
  --voice 1.5 --no-pause-scale --keyboard 2 --wait 5 --answer 1.5 --visual "$WORK/visual.json"
python3 scripts/narration.py render --src "$SRC" --plan "$WORK/plan.json" \
  --out "$EDITED" --confirmed --fps 30 --crf 24
```

Вместо `--no-pause-scale` можно передать, например, `--pauses '2:2,4:2.5,6:3,10:3.5,16:4,26:4.5,42:5' --short-pause 1`. Порог строгий: пауза ровно четыре секунды попадает под «дольше двух», а не «дольше четырёх». Шкала применяется только к остатку паузы после учёта экранных событий. При отключённой шкале остаток идёт на 1×.

План охватывает всю запись, привязан к содержимому исходного файла и содержит скорости каждого участка. Рендер растягивает звук без изменения высоты, переносит кадры по той же шкале, проверяет обе длительности и декодирует файл целиком. Для проверки возьмите переходы между режимами, сопоставьте исходный и новый кадры, прослушайте начало и конец фраз.

## Повторное сжатие при прежнем монтаже

На отрывках с самым мелким и бледным текстом, прокруткой и появляющимися буквами сравните несколько настроек. Для пробы извлеките отрывки в одинаковом исходном разрешении с видео без потерь. Сопоставьте одинаковые кадры при масштабе 100%, посмотрите движение курсора, измерьте байты. Оставьте настройки, при которых качество устраивает пользователя. Снижение частоты кадров меняет плавность и может пропустить краткое состояние интерфейса.

На выбранной частоте программа извлекает одинаковые номера кадров исходной и конечной шкалы. В `--crop` передайте левую и верхнюю координаты, ширину и высоту фактической области с текстом. В `--at` — секунды по часам готового монтажа. Например:

```sh
python3 scripts/compact.py --src "$EDITED" --out "$SMALL" \
  --fps 15 --crf 28 --crop 100 80 700 360 --at 2 12 24 --proof "$WORK/proof"
```

Сверьте пары source/compact в папке проверки. Результат должен стать меньше при прежней геометрии, длительности и звуке. Если дан предел, передайте `--target-mb` в десятичных мегабайтах. Файл, который не стал меньше или превысил лимит, не публикуется как удачное сжатие. Пути к записям, кадры и разметка реального пользователя остаются в локальной рабочей папке.
