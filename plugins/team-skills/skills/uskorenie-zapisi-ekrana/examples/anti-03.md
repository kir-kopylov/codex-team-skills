# Ожидался голос, а файл без звуковой дорожки

## Вход

«В моей длинной записи есть комментарий. Ускорь паузы». Выбран короткий клип без звуковой дорожки.

## Ожидаемое Поведение

Навык сверяет фактические длительность и наличие звуковой дорожки с описанием, ищет подходящий источник и при неоднозначности уточняет только его. Речевой монтаж не начинается с противоречивого файла. Если пользователь намеренно выбрал немую запись, можно применить согласованный план с таймкодами.

## Нельзя

Нельзя принять весь немой файл за одну речевую паузу, разогнать его целиком и представить как нужную версию с голосом.
