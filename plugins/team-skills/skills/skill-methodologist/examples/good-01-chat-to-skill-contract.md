# Длинный Чат В Контракт Skill

## Вход

Пользователь пишет: "У нас был длинный чат про еженедельную проверку квартир перед заселением: фото, стоп-факторы, готовность кухни, что просить у агента, как не путать ремонт с готовностью к посуточной аренде. Сделай из этого контракт skill, но пока без файлов repo."

## Ожидаемое Поведение

Codex использует `skill-methodologist`: выделяет повторяемую задачу, входы, ожидаемый результат, правила, анти-правила, алгоритм проверки, self-checks и формат ответа. Он возвращает контракт skill, где отдельно указано, что следующий шаг для упаковки в repo - `add-team-skill`.

Контракт должен сохранить рабочие правила: не угадывать состояние квартиры без фото, отделять booking-photo effect от ремонта, помечать missing measurements и спрашивать только критичный следующий blocker.

## Нельзя

Нельзя создавать folder в repo, править `catalog.md`, запускать tests или открывать Pull Request. Нельзя копировать весь чат как инструкцию; нужно извлечь повторяемый рабочий процесс и проверяемые правила.
