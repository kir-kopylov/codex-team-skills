# Контракт Для Повторяемого Отчета

## Вход

Пользователь пишет: "Каждый месяц я получаю Excel с продажами, вручную считаю отклонения, делаю короткий management summary и отдельный список строк, где данные не сходятся. Хочу понять, нужен ли skill и нужен ли script."

## Ожидаемое Поведение

Codex использует `skill-methodologist`: проверяет признаки повторяемости, формулирует назначение skill одной фразой, задает контракт входов и результата, предметные правила, правила качества, анти-правила, алгоритм и проверки. Он отдельно решает, что script нужен, если расчеты, row counts и reconciliation должны быть воспроизводимыми.

Результат должен быть не общим советом, а контрактом будущего skill с явными секциями: обязательные файлы, output workbook, management summary, data checks, unmatched records, failure behavior.

## Нельзя

Нельзя делать dashboard или писать финансовую модель без исходных правил. Нельзя угадывать формулы, если пользователь не дал business logic; такие места нужно отметить как `[requires recheck]`.
