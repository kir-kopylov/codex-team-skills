# Анти-Пример: текстовый token budget назван hard stop

## Вход

Пользователь указал лимит токенов. Runtime сообщает, что точный token counter
между tool calls недоступен и budget имеет класс `advisory`.

## Ожидаемое Поведение

Skill сохраняет числовой лимит, но помечает его `advisory`, добавляет доступный
hard action/time stop и объясняет, какое событие реально остановит следующий
покрытый вызов.

## Нельзя

Нельзя называть обещание модели hard stop; завершать shaping без различения
счётчика, наблюдаемого события и механизма запрета.
