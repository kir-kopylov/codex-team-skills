# Хороший Пример: универсальный процесс создания ценности

## Вход

Пользователь пишет: "Проверь цель для /goal. Сырая цель: запустить локальную волонтерскую инициативу, чтобы группа жителей регулярно помогала пожилым соседям с бытовыми задачами. Codex не может сам звонить людям, обещать помощь, распоряжаться деньгами или принимать решения за координатора".

## Ожидаемое Поведение

Codex применяет `goal-contract-shaper`, потому что задача не сводится к одному совету: есть люди, доверие, ответственность, внешние ответы, риски, повторяемый цикл и проверяемый результат. Он не начинает планировать кампанию и не пишет сообщения от имени пользователя.

Сначала Codex выявляет универсальную грамматику деятельности: объект работы, создаваемую ценность, конечный результат, текущие сигналы движения, роли координатора/волонтеров/получателей помощи, единицу действия, единицу проверки, единицу потери, допустимые затраты, риски доверия и журнал круга.

Контракт оформляется как сопровождаемый человеческий цикл: Codex предлагает один ближайший ход и готовит материалы, координатор решает и действует в мире, круг закрывается только после сообщения координатора о результате. В контракте отдельно фиксируются правила ожидания, зависания, запасного хода и partial result.

## Нельзя

Нельзя считать, что Codex "ведет инициативу" без владельца действий. Нельзя подменять подтвержденную помощь советом, смешивать действие с проверкой, скрывать цену ошибки для пожилых людей, обещать внешние действия или тратить деньги/доверие без решения пользователя.
