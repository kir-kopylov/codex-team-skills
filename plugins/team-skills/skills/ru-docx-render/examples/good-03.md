# Хороший Пример: Markdown в docx через CLI

## Вход

У пользователя готовый текст акта в `markdown`: первая строка `# АКТ
ПРИЁМКИ РАБОТ`, подзаголовки через `##`, остальное — абзацы. Просьба:
«сделай из этого `Word`-файл по стандарту, ничего не меняя в тексте».

## Ожидаемое Поведение

Skill запускает `python3 scripts/render_docx.py --in akt.md --out akt.docx`.
`markdown`-подмножество отображается один в один: `# ` → `title`, `## ` →
`heading`, остальные непустые строки → `para`. Оформление — стандартное
(`Times New Roman`, `A4`, поля). Содержание не редактируется.

## Нельзя

Нельзя «улучшать» формулировки, добавлять разделы, которых нет во входе, или
отдавать результат в формате, отличном от `.docx`.
