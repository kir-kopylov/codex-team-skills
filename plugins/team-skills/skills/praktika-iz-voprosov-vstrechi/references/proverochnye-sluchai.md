# Проверочные случаи

Это условия оценки, а не подсказки для проверяемого наставника. Применимые случаи включайте в полный маршрут, несовместимые развилки — в отдельную пробу той же версии.

| Ситуация | Наблюдаемый ожидаемый результат |
| --- | --- |
| Выбрано нативное приложение | Проверка идёт в нём; браузер не запускается как замена |
| Отправлен только файл | Наставник начинает занятие и даёт один лёгкий шаг |
| «Зачем мне это?» | Связывает действие с собственным вопросом ученика, упрощает шаг и продолжает |
| «У меня два окна» | Называет оба места, действие и место возврата |
| Вопрос посреди эпизода | Сначала отвечает, затем возвращает к одному ближайшему действию |
| Настройка уже сделана | Использует прежнее состояние; не объявляет новое подключение |
| Материала достаточно | Сразу выдаёт полезный результат, предлагает правку или принятие |
| Два варианта на одном материале | Каждый выбор ведёт к заявленному действию и готовому результату |
| «Не вижу кнопку» со снимком | Разбирает реальный прикреплённый снимок; не повторяет выдуманный маршрут |
| Пауза, затем продолжение | Сохраняет точку и возвращается к ней без повторного опроса |
| Доступ недоступен | Называет предел обхода и не закрывает основную ветку успехом |
| Один эпизод успешен, другой только обойдён | Полный основной прогон остаётся незавершённым |
| После прогона файл исправлен | Новая версия проходит весь маршрут в новом чате |
| Финальная памятка | Отражает фактические результаты, отвечает на вопросы, содержит способ повторения |

Не требуйте все сочетания веток. Не заявляйте понимание ученика по ответу «да». Технический успех загрузки не подтверждает весь сценарий.

## Выбор на одной учебной переписке

В обоих запусках используются одни и те же вымышленные письма и позиция ученика. Меняется только выбор после меню «Собрать факты» или «Подготовить ответ». Критерии проверки держите у проверяющего.

### Учебная переписка

- П1, 12 мая, Марина. «Предлагаю три занятия за 45 000, оплатить до 20 мая».
- П2, 13 мая, ученик. «Можем провести два занятия за 30 000 с оплатой до 22 мая?»
- П3, 14 мая, Марина. «Согласна на два занятия за 30 000. Оплата до 22 мая».
- П4, 16 мая, Марина. «Для договора нужен список участников. После получения списка пришлю договор».

Позиция ученика — подтвердить согласованные условия. Список участников сможет прислать завтра.

### Проверка результата

| Ответ ученика | Что должно получиться |
| --- | --- |
| «Собрать факты» | Готовая таблица со ссылками на номера писем. Отражены исходное предложение, согласованные два занятия за 30 000 до 22 мая и условие отправки договора. |
| «Подготовить ответ» | Готовый черновик для Марины. Подтверждены два занятия за 30 000 и срок оплаты 22 мая, указано, когда ученик пришлёт список. Черновик остаётся в чате. |

Сверьте оба результата с письмами и позицией ученика. Две одинаковые сводки, подмена черновика перечнем тезисов или обещание сделать результат в будущем означают провал этой пробы.
