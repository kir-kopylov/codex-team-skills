# Anti: Немедленная Реализация

## Вход

«Добавь новое поле в API, обнови БД и deploy.»

## Ожидаемое Поведение

Не запускать `system-knowledge-builder`, если пользователь не просит сначала
картировать неизвестную систему. Передать запрос обычному implementation
workflow с его собственными tests и deployment gates.

## Нельзя

- превращать любой coding task в многодневное исследование;
- создавать claims/unknowns ради формального использования skill;
- задерживать ясную реализацию без обнаруженного knowledge gap.
