# Domain Playbook

Служебная память skill по интерфейсам источников цен. Обновляется через sanitized-карточки сбоев; сырые логи сюда не попадают.

## Что Нельзя Потерять

- Инвариант отсечения: вход, достижимый только стыковкой через другой вход, не может быть дешевле своего первого плеча — полный перебор нужен только по гейту.
- Карточка плеча со статусами `live / оценка / регулируемый / стена` — ни одно число без статуса.
- Багажная конфигурация пользователя как условие сравнения кандидатов.
- Дни курсирования для наземных плеч.
- Метка времени каждого снимка цены: дешёвые прямые тарифы распродаются за часы.

## Что Надо Обезличить

- Реальные лимиты бюджета, даты поездок и города конкретного пользователя — в примерах и логах заменять условными.
- Номера карт, банки, валюту карты пользователя — упоминать только классом («карта, работающая в стране Х»).
- Приватные пути, скриншоты и сырые выгрузки страниц — не коммитить; в repo только выводы.

## Interface Mechanics

- Агрегатор класса aviasales: страница поиска открывается прямым URL-шаблоном `/search/{IATA}{ДДММ}{IATA}{пассажиры}` (например `/search/AAA1503BBB1`) — без боя с формой.
- Заголовок вкладки после перехода уже содержит минимальную цену и маршрут («NN NNN ₽ | AAA → BBB, 15.03») — часто этого достаточно, ноль дополнительных вызовов.
- Лента «цены на соседние даты» на странице выдачи покрывает окно ±несколько дней одним заходом; короткий текст страницы дешевле скриншота.
- Точка продажи задаётся доменом: `.ru` — цены в рублях, `.kz` — в тенге; это разные пулы цен одного движка, сравнивать через живой курс.
- Западные метапоиски (Google Flights, Skyscanner) слепы для маршрутов из РФ — для этого региона источник только региональный агрегатор плюс сайты перевозчиков.
- Гос-ж/д касса (класс bilet.railways.kz): тарифы регулируемые, прямых мест в сезон может не быть — выдача показывает составные маршруты с гарантией пересадки от часа; поиск маршрутов за reCAPTCHA — это «стена».

## Recovery And Edge Cases

- Датапикер не принимает дату из form_input: один повтор через клик по ячейке календаря; не помогло — считать в бюджет сайта и при исчерпании ставить «стену».
- Сайт-агрегатор редиректит на ребрендированный домен и отдаёт 404 по старому URL-шаблону: один заход через главную форму; форма игнорирует ввод — «стена», не перебирать механизмы по кругу.
- Клики по координатам мажут при масштабированном скриншоте: кликать по ref из дерева элементов, а не по пикселям.
- Город-омоним в подсказке (одинаковые названия в разных странах): выбирать пункт только с проверкой IATA-кода и страны.
- Цена в ленте дат «Найти» вместо числа: считать дату непокрытой кэшем, а не нулевой ценой; минимум окна брать только по известным дням с пометкой.
- Вкладка браузера закрылась между шагами: переоткрыть и продолжить с текущего кандидата, baseline не пере-снимать, если снят в этом прогоне.
