# Отнесение Расходов На Квартиры

## Прямые Расходы

Прямой расход можно отнести на квартиру, если в строке есть надежный ключ квартиры: адрес, объект, подразделение, номенклатурная группа, договор, контрагент или документ с понятной привязкой.

Обычно прямые:

- аренда собственнику;
- коммунальные услуги;
- интернет, ТВ, домофон;
- ремонт, мастер, запчасти;
- мебель, техника, замки, матрасы;
- адресная уборка или адресная комиссия площадки.

## Распределяемые Расходы

Если поквартирный учет не велся, расход остается расчетным. Его можно включать в управленческую маржу только с отдельной пометкой.

Обычно распределяемые:

- стирка и прачечная;
- туалетная бумага, чай, сахар, кофе, жидкое мыло, бытовая химия;
- белье, полотенца и текстиль;
- зарплата администратора;
- зарплата обслуживающего персонала;
- офисные и общие операционные расходы.

## Базы Распределения

| Расход | База По Умолчанию | Альтернатива |
| --- | --- | --- |
| Стирка | уборки | бронирования |
| Расходники | бронирования | ночи проживания |
| Белье | уборки | ночи или спальные места |
| Зарплата администратора | выручка | бронирования |
| Обслуживающий персонал | уборки | бронирования или квартиро-месяцы |
| Офисные расходы | выручка | квартиро-месяцы |

## Формулировка Для Отчета

Используйте короткое предупреждение:

```text
Стирка, расходники, белье и зарплата распределены расчетным методом, так как фактический поквартирный учет за период не велся. База распределения указана отдельно.
```

## Не Включать Без Проверки

- депозиты гостей;
- возвраты гостям;
- внутренние переводы между счетами;
- авансы собственникам без начисленного расхода;
- погашение задолженности, если оно относится к другому периоду;
- закупки, которые относятся к нескольким объектам без базы распределения.
