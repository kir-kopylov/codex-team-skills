# Проектирование Будущей Цели

## Вход

«Составь контракт для ночной `/goal`: определи финал, полномочия, доказательства, остановки и условие завершения».

## Ожидаемое Поведение

Skill не применяется. Здесь нужно спроектировать будущий цикл до выполнения, поэтому запрос маршрутизируется в `goal-contract-shaper`. Аудитор пригодится позднее, если нужно будет проверить уже работающую реализацию либо предъявленный пакет доказательств.

## Нельзя

Нельзя дублировать полный workflow проектирования `/goal` внутри узкого аудитора завершения.
