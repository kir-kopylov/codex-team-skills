# Анти-Пример: Неподтверждённое Закрепление

## Вход

«Поставь мой промпт самым первым после `/`.»

## Ожидаемое Поведение

Skill создаёт разумный alias только после проверки существующих механизмов и честно сообщает, если продукт не даёт API закрепления. Для подтверждения позиции просит свежий UI-state.

## Нельзя

Писать «готово, теперь он точно всегда первый», если порядок меню не был увиден в текущей среде.
