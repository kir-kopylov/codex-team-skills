# Хороший Пример: Уже Существует Skill

## Вход

«Я каждый раз копирую один и тот же промпт. Проверь, нет ли уже skill, и сделай самый быстрый запуск. Работаю только в CLI.»

## Ожидаемое Поведение

Skill фиксирует пользовательский scope и ищет существующие skills с тем же поведением. Переиспользует только enabled skill нужного scope, фактически доступный в CLI; repo-scoped вариант при явной цели переносит в отдельный пользовательский skill через name/collision gates, disabled пользовательский не дублирует и диагностирует read-only, а enabled с discovery `false/unknown` проверяет без записи и не более чем одним restart. Для пользовательского варианта сначала проверяет `$HOME/.agents/skills/<имя>/SKILL.md`. До изменения фиксирует безопасную репрезентативную пробу исходного prompt. На выбранной CLI-поверхности возвращает `состояние на диске: переиспользован`, отдельно проверяет `/skills`, вызов через `$имя` и сохранение поведения на этой пробе; статусы ChatGPT desktop app и запросы про список после `/` возвращает как `не применимо`, не требуя нерелевантного скриншота.

## Нельзя

Создавать второй почти идентичный skill, переиспользовать вариант неверного scope или disabled-state, называть `$имя` отдельной `/имя`-командой, считать один успешный запуск доказательством сохранения поведения или задерживать готовый CLI-сценарий ради проверки настольного приложения.
