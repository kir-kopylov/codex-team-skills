# Анти-Пример: Plugin После Первой Неудачи

## Вход

«Я положил личный prompt в папку skills, но его не видно. Сделай уже как угодно, лишь бы появилась `/zachem`.»

## Ожидаемое Поведение

Skill обнуляет уверенность в выбранном механизме и сверяет текущую документацию. Даже если прежний plugin отмечен как `installed, enabled` и содержит файл в cache, skill фиксирует `видно: нет`, `фактический вызов: нет`, `цель достигнута: нет`. После определения ОС он использует пользовательский path `%USERPROFILE%\.agents\skills\zachem\SKILL.md` на Windows или `$HOME/.agents/skills/zachem/SKILL.md` на macOS/Linux, проверяет frontmatter и UTF-8, объясняет вызов `$zachem`, выполняет не более одного restart и просит один свежий UI-state. Plugin рассматривается только при отдельной цели распространения.

## Нельзя

Создавать `commands/zachem.md`, отдельный marketplace, менять manifest по догадке или вручную переписывать `config.toml`, особенно при кириллице в user path.
