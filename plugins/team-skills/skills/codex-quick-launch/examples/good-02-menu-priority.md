# Хороший Пример: Приоритет В Меню

## Вход

«Мне нужно нажать `/` и сразу выбрать эту команду. Не хочу искать в длинном списке.»

## Ожидаемое Поведение

Skill отделяет желаемое удобство от механизма. Сначала использует наблюдаемую текущую поверхность, а если её нельзя определить из входа или среды, задаёт один вопрос: «Где нужен быстрый вызов: ChatGPT Desktop, CLI или IDE?» Только для выбранного ChatGPT Desktop он объясняет, что enabled skill должен появиться в slash-списке, а явно вызывается через `$короткое-имя`; документированного API первого места нет. Ничего не переименовывает ради сортировки; отдельно возвращает применимые статусы `видно в slash-списке`, `вызов через $имя` и `первое после /`.

## Нельзя

Обещать отдельную slash-команду, добавлять `00-` как суррогат закрепления или менять config/plugin ради неподтверждённой позиции.
