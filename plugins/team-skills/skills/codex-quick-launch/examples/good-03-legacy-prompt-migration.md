# Хороший Пример: Старый Custom Prompt

## Вход

«У меня есть старый файл custom prompt, но после обновления Codex его нет в меню. Сделай, чтобы привычный сценарий снова запускался быстро.»

## Ожидаемое Поведение

Skill проверяет, поддерживается ли custom prompt в текущем runtime. Если нет, создаёт эквивалентный пользовательский skill в `$HOME/.agents/skills/<имя>/SKILL.md`, не удаляет исходный файл без согласия и объясняет вызов `$имя`. После этого отдельно проверяет или помечает как неподтверждённые обнаружение в Skills и фактический вызов.

## Нельзя

Создавать skill в недокументированном path, считать прежний формат поддерживаемым по умолчанию, удалять старый файл или утверждать, что миграция сработала без проверки `$имя`.
