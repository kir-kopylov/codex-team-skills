# Хороший Пример: Старый Custom Prompt

## Вход

«У меня есть старый файл custom prompt, но после обновления Codex его нет в меню. Сделай, чтобы привычный сценарий снова запускался быстро.»

## Ожидаемое Поведение

Skill проверяет, поддерживается ли custom prompt в текущем runtime. Если нет, создаёт эквивалентную локальную skill, не удаляет исходный файл без согласия и объясняет новый короткий вызов. После этого отдельно проверяет или помечает как неподтверждённые загрузку и UI-видимость.

## Нельзя

Считать прежний формат поддерживаемым по умолчанию, удалять старый файл или утверждать, что миграция сработала без нового UI-state.
