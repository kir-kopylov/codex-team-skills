# Хороший Пример: Старый Custom Prompt

## Вход

«У меня есть старый файл custom prompt, но после обновления Codex его нет в меню. Сделай, чтобы привычный сценарий снова запускался быстро. Короткое имя хочу `Fast_Migration`.»

## Ожидаемое Поведение

Skill проверяет, поддерживается ли custom prompt в текущем runtime. Если нет, до записи нормализует имя в `fast-migration`, проверяет формат и длину, показывает итоговый вызов `$fast-migration`, а затем создаёт эквивалентный пользовательский skill в `$HOME/.agents/skills/fast-migration/SKILL.md`. Исходный файл без согласия не удаляет. После этого отдельно проверяет или помечает как неподтверждённые обнаружение в Skills и фактический вызов.

## Нельзя

Записывать `Fast_Migration` как имя папки или поле `name`, создавать skill в недокументированном path, считать прежний формат поддерживаемым по умолчанию, удалять старый файл или утверждать, что миграция сработала без проверки `$имя`.
