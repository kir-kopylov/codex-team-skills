# Разовая Или Концептуальная Задача

## Вход

Пользователь пишет: "Разбери эту идею: почему команда путает процесс и результат. Мне нужно понять мысль, а не создавать skill."

## Ожидаемое Поведение

Codex не использует `kontrakt-navyka-do-sborki`, потому что пользователь просит conceptual analysis без намерения получить повторяемый skill contract. Подходящий routing - `razbor-svoey-syroy-idei`.

Если пользователь позже скажет, что эта мысль должна стать повторяемым рабочим процессом, тогда можно вернуться к `kontrakt-navyka-do-sborki`.

## Нельзя

Нельзя насильно создавать skill contract из каждой сильной идеи. Нельзя спрашивать про inputs, outputs и scripts, если пользователь просит только разобраться в концепции.
