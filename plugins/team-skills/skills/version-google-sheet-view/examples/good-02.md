# Хороший Пример: Обновление Контракта

## Вход

«Обнови `config/deals-view.yaml` по живой вкладке. В файле есть мой ключ `notes` — его не трогай».

## Ожидаемое Поведение

Skill сначала проверяет только целевой путь. Если файл не был изменён до запуска, он читает живую вкладку и точечно заменяет лишь `provenance` и `view_contract`, сохраняя `notes` без изменений. Затем выполняет повторное чтение и возвращает `MATCH` либо точный `DRIFT`. Если целевой файл уже имеет чужие незакоммиченные правки, результат — `BLOCKED` без перезаписи.

## Нельзя

Нельзя пересобирать весь файл с нуля, удалять неизвестные верхнеуровневые ключи, присваивать себе предшествующие изменения или продолжать запись после обнаруженного конфликта.
