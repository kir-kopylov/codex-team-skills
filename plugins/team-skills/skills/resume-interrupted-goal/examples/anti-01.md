# Неизвестный Репозиторий После Архивной Session

## Вход

Пользователь называет только архивную задачу Codex и просит найти, в каком repo, worktree или commit осталась работа, а затем продолжить её.

## Ожидаемое Поведение

Skill возвращает `AMBIGUOUS_TARGET`. Единственный следующий шаг — применить `codex-session-to-repo-rescue` в режиме read-only map, чтобы доказать цепочку session → cwd → repo/worktree → commit → target. Любое продолжение или публикация остаются отдельными действиями после восстановления карты.

## Нельзя

Сканировать raw sessions собственным parser, угадывать target по названию задачи, создавать branch, commit, push или PR/MR.
