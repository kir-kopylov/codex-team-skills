# Конфликт Route И State

## Вход

Route проекта говорит: «первый рабочий цикл не запущен». Рядом находится state со статусом `ACTIVE_REVIEW_PENDING`, а в working tree есть созданные, но не принятые документы. Память чата утверждает, что цикл завершён.

## Ожидаемое Поведение

Skill возвращает `RECONCILE_REQUIRED`. Он дословно показывает конфликт и не выбирает победителя по свежести файла. Единственный следующий шаг: владелец runtime или проекта сверяет identity из state с текущим состоянием задачи. Проверка: route и state после отдельного решения называют один и тот же цикл и этап. Новый цикл не запускается.

## Нельзя

Считать state истинным только потому, что он новее, объявлять документ принятым, удалять файлы или продолжать выполнение.
