# Согласованное Продолжение

## Вход

После перезапуска Codex пользователь просит продолжить `/goal`. Управляющие файлы называют один цикл и один репозиторий. Валидная контрольная точка содержит recorded HEAD и последнее применённое событие; Git и документы совпадают с ней. Хвост после курсора показывает, что независимый review ещё не начинался.

## Ожидаемое Поведение

Skill ничего не меняет и возвращает `RESUME_SAFE`. В подтверждённом перечисляет точные источники, в «Не повторять» — уже завершённое исследование. Единственный следующий шаг: передать выбранный документ независимому ревьюеру по правилам контракта. Проверка: появляется наблюдаемый результат review. После результата skill запускает обязательный опрос.

## Нельзя

Перечитывать весь журнал, повторять исследование, менять state, запускать новый цикл, commit или push.
