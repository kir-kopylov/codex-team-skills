# Хороший Пример: Разные Разрешения Мониторов

## Вход

«Сделай такой же сетап, но на этом компьютере один экран 2560×1440, второй 1920×1080 и расположен в Windows слева».

## Ожидаемое Поведение

Codex сначала читает фактическую конфигурацию и строит стабильный холст для анализа: экраны стоят рядом без масштабирования, ширина холста равна 4480, высота — 1440. Источники получают точные размеры и X-координаты, после чего проверяются контрольными кадрами. Частные значения 3840×1080 из прежнего компьютера не используются.

## Нельзя

Нельзя слепо выставлять 3840×1080, уменьшать оба экрана до 1920×1080 или считать чёрный зазор приемлемым без проверки читаемости текста.
