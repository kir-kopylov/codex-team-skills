# Три модели четырёх стульев

## Вход

«Замени все четыре стула у стола на три варианта, по два изображения каждого». Даны два совместимых вида одного помещения и три описания моделей.

## Ожидаемое Поведение

Зафиксировать K=4, N=3, M=2 и provided_concepts: всего шесть изображений. Использовать по одному результату с каждого исходного вида. Для каждого варианта согласованно заменить четыре стула; стол, комнату и освещение сохранить. Проверенный первый кадр использовать только как эталон стульев во втором.

## Нельзя

Путать четыре экземпляра с числом файлов, менять стол, переносить камеру первого вида во второй или делать четыре разных модели в одной композиции.
