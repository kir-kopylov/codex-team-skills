# Сценарии использования

## Автоматические концепции

Даны два вида пустой гостиной. Пользователь просит пять диванов по два изображения для объявления посуточной аренды. Навык создаёт пять конструктивно различающихся вариантов, использует по одному кадру с каждого реального вида и получает десять результатов.

## Заданные концепции

Пользователь описал четыре модели стола и приложил два вида комнаты. Число вариантов выводится из списка; описания нормализуются без добавления новых признаков.

## Конкретные товары

Даны три группы фотографий кресел. Каждая группа становится отдельным вариантом. Невидимые стороны отмечаются как приблизительные; цена, материал и наличие не подтверждаются визуализацией.

## Одна ось различий

Пользователь просит пять цветов одной модели кровати. Геометрия, опоры и оформление сохраняются; отличаются только заказанные цвета.

## Один исходный вид и несколько изображений

При M=3 создаются v01-t01, v01-t02 и v01-t03. Все три — отдельные генерации с одной камерой. Новый угол, крупный план, обрезка или копия не засчитываются.

## Предмет с состоянием

Для светильника варианты «включён» и «выключен» считаются двумя вариантами. Это не скрытое удвоение M. Остальные источники света сохраняются, если пользователь не попросил иного.

## Исправление и продолжение

После готовой серии пользователь просит изменить только ножки третьего варианта. Создаётся новая редакция: сначала основной кадр третьего варианта, затем остальные его кадры. Другие варианты и старая редакция сохраняются.

## Граница

Запрос заменить диван, кухню, двери, свет и отделку во всех комнатах не относится к этому навыку. Его нужно маршрутизировать в процесс комплексного проектирования, не сужая задачу молча.
