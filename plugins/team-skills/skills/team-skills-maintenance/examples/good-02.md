# Хороший Пример: Первая Установка

## Вход

«Установи свежую каноническую библиотеку skills».

## Ожидаемое Поведение

JSON-список не содержит `team-skills@codex-team-skills`. Codex подключает `kir-kopylov/codex-team-skills` с ref `main` штатной командой marketplace, затем отдельно выполняет `codex plugin add team-skills@codex-team-skills --json`. После этого он снова читает JSON-список и проверяет ровно одну включённую запись, Git-источник и semver.

Если marketplace уже существует, Codex не угадывает его происхождение: он принимает ветку «уже подключён» только после подтверждения того же source, затем делает upgrade и повторный plugin add.

## Нельзя

Нельзя заменять штатный путь скачанным скриптом, прямой правкой cache или одним `git pull`. Обновление marketplace не является переустановкой plugin.
