## Ожидаемое Поведение

Codex сначала напоминает, что автообновление работает раз в двое суток, затем запускает update script для текущей ОС. После успешного обновления Codex просит перезапустить Codex, чтобы plugin был перечитан.

## Нельзя

Нельзя скачивать сырой `main` вместо проверенного release-bundle и нельзя удалять старую рабочую версию при ошибке обновления.
