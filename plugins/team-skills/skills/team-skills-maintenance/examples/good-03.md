# Хороший Пример: Точный Дубль И Уникальный Навык

## Вход

«Обнови Team Skills и убери локальные дубли».

## Ожидаемое Поведение

В проверенном личном корне есть обычные каталоги `verify` и `my-private-workflow`. Новый канонический plugin содержит `verify`, но не содержит `my-private-workflow`; frontmatter локального `verify/SKILL.md` точно совпадает с именем папки, а ссылок и выходов за root нет.

Codex записывает дерево и SHA-256, атомарно переносит только `verify` в новый каталог карантина, проверяет источник и target и оставляет `my-private-workflow` байт-в-байт без изменений. В manifest остаётся путь восстановления. Постоянного удаления в этом запуске нет.

## Нельзя

Нельзя перемещать все папки личного root, считать похожее описание дублем, следовать symlink или очищать резервные cache-каталоги.
