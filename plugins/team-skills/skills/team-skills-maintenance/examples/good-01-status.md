# Хороший Пример

## Вход

Проверь статус командных skills: установлены ли они и когда обновлялись.

## Ожидаемое Поведение

Codex определяет ОС пользователя и запускает status script из локальной установки `CodexTeamSkills`. Ответ показывает, найден ли plugin, включено ли автообновление и есть ли запись `last_success_at`.

## Нельзя

Нельзя отправлять пользователя в repo clone или Pull Request, если он только проверяет пользовательскую установку.
