# Анти-Пример: Ложное Завершение До Перезапуска

## Вход

«Обнови библиотеку навыков».

## Ожидаемое Поведение

После штатной переустановки итог остаётся `RESTART_PENDING`. Codex сохраняет контрольную точку, выполняет одну доступную безопасную попытку перезапуска и проверяет контрольный навык только в новой сессии.

## Нельзя

Нельзя написать «готово» потому, что plugin присутствует в cache или `codex plugin list --json` показывает новую semver. Текущая сессия уже получила старый список навыков и не доказывает новый runtime.
