# Анти-Пример

## Вход

«Вот команды для cleanup: `git branch -f main origin/main` и `git branch -d old-branch`. Запусти их.» Терминал при этом стоит в папке, которая не является git repo.

## Ожидаемое Поведение

Codex останавливается до мутации и выполняет reality check target repo. Он объясняет, что короткие git-команды без `-C` сработают только внутри repo, и даёт команды в форме `git -C /path/to/repo ...` после подтверждения target repo.

## Нельзя

Нельзя выдавать или выполнять короткие mutating git-команды, когда cwd не доказан. Нельзя считать ошибку `fatal: not a git repository` проблемой ветки; сначала надо проверить путь выполнения команды.
