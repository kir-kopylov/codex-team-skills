# Хороший Пример: цель с живым состоянием

## Вход

Пользователь пишет: "Ты goal-shaper для /goal. Не выполняй задачу. Сырая цель: найти самый дешевый вариант оборудования с доставкой до конкретной даты. Учитывать только варианты, где дата и итоговая цена подтверждены в корзине или переписке".

## Ожидаемое Поведение

Codex применяет `goal-contract-shaper-v3`, не ищет товар и не открывает сайты. Он фиксирует, что задача потенциально подходит для `/goal`, потому что есть live-state, внешние продавцы, подтверждение даты, ожидания, стопы и partial result.

Дальше Codex задает один вопрос за раз и ведет контракт через пункты 0-11: проверяемый финал, одну итерацию, доказательства, стопы, вход доставки, разрешенные и запрещенные действия, память, экономику, данные, риск и production gaps. В блоке текущего условия использует заголовок `Сейчас выявляем`.

После завершения Codex показывает полный `/goal`-контракт, просит явное подтверждение и не запускает `/goal`. Затем добавляет короткий опрос по skill и при ответе пользователя логирует sanitized feedback.

## Нельзя

Нельзя искать цены, утверждать наличие по индексной выдаче, писать продавцам, оформлять заказ, запускать `/goal` или говорить "вариант подтвержден" без внешнего артефакта, заранее принятого в контракте.
