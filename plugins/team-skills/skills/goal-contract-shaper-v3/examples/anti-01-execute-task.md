# Анти-Пример: пользователь просит выполнить задачу

## Вход

Пользователь пишет: "Найди и купи самый дешевый вариант с доставкой завтра" или "Проверь сайт и скажи, что сейчас есть в наличии" без просьбы сформировать `/goal`-контракт.

## Ожидаемое Поведение

`goal-contract-shaper-v3` не должен автоматически перехватывать прямое выполнение. Если пользователь явно хочет действие по живому состоянию, нужно выбрать более подходящий workflow или skill для live-state verification, а не shaping.

Если в запросе есть риск и неясные полномочия, Codex может коротко предложить сначала сформировать `/goal`-контракт, но не должен навязывать этот skill как обязательный.

## Нельзя

Нельзя под видом shaping начинать поиск, оформлять заказ, связываться с продавцом, утверждать live-state или превращать прямой запрос пользователя в долгий контракт без согласия.
