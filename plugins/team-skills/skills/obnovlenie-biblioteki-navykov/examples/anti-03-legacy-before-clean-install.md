# Анти-Пример: Чистая Установка Поверх Старых Следов

## Вход

Plugin отсутствует в `codex plugin list --json`, но на машине сохранились прежний каталог Team Skills и управляемый config-блок.

## Ожидаемое Поведение

До изменяющих команд поставить `LEGACY_TRANSITION_REQUIRED` и перейти к `START_HERE_RECONNECT_CODEX_SKILLS.md`. Каждый след изменяется лишь после точной проверки владения; неоднозначность даёт `BLOCKED_LEGACY_OWNERSHIP`, а не массовую очистку.

## Нельзя

Нельзя сразу выполнять `marketplace add` и `plugin add`: новая установка смешает состояния и может оставить старую копию активной или затруднить доказательство владения файлами.
