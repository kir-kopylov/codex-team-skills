# Установленный Plugin С Локальным Marketplace

## Вход

«Переподключи Team Skills к Git marketplace, чтобы обновление снова работало».

Синтетическое наблюдение: plugin установлен и включён; регистрация marketplace имеет `source_type = "local"`. Точный source и manifests подтверждают отдельный локальный Team Skills. Чужих plugins в этой регистрации нет. Каталог находится внутри Git checkout.

## Ожидаемое Поведение

Агент выбирает `LEGACY_TRANSITION_REQUIRED` независимо от installed, выполняет сохранение конфигурации и пакета, условную сверку с свежим SHA main и уже разрешённое переподключение. Проверяет Git-регистрацию и установку обратно. Повторного разрешения на тот же переход не спрашивает.

Контрпример для различения слоёв: `marketplaceSource.sourceType = "git"` и `source.source = "local"` у папки plugin означают обычный Git marketplace с локальным путём внутри него, поэтому сами по себе не требуют reconnect.

## Нельзя

- Нажимать Upgrade для локальной регистрации или выводить её тип из Git origin.
- Требовать отсутствия plugin как предусловия переподключения.
- Удалять общий marketplace с чужими plugins либо неизвестный источник.
