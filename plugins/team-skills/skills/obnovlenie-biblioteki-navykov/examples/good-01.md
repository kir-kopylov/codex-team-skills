# Хороший Пример: Один Полный Вызов

## Вход

«Обнови библиотеку навыков».

## Ожидаемое Поведение

Codex воспринимает первую фразу из каталога как разрешение на весь цикл и не спрашивает отдельно про marketplace, переустановку, карантин и одну попытку перезапуска. Сначала он проверяет `codex --version`, `codex plugin --help` и JSON-список. Если штатная CLI исправна, он обновляет канонический marketplace, повторно устанавливает plugin, проверяет точные одноимённые личные конфликты и переносит только доказанные конфликты в карантин с manifest и хэшами.

Перед перезапуском Codex сохраняет `pending.json`. Завершением считается только `LIVE_VERIFIED` после проверки контрольного навыка в новой сессии. Если безопасного restart/resume-механизма нет, итог честно остаётся `BLOCKED_RESTART_UNAVAILABLE` с одним ручным действием; уже выданное разрешение не запрашивается повторно.

## Нельзя

Нельзя остановиться после обновления Git-источника, назвать файлы на диске живым результатом или перекладывать на пользователя отдельные решения по каждому заранее оговорённому шагу.
