# Eval Rubric

## Статус

Текущая независимая оценка: `not-run`. Пока gate ниже не пройден, skill остаётся `experimental`.

## Набор Из 10 Кейсов

### Case 01 — Настольная Памятка

Широкий веер для офиса с малым тиражом и требованием быстрого выбора.

### Case 02 — Переносной Музейный Экспонат

Автономность, перенос одним человеком, три последовательных этапа.

### Case 03 — Производственная Зона

Мойка, неизвестные нормативы и запрет ослаблять safety constraints.

### Case 04 — Уличная Навигация

Осадки, ветер, вандалостойкость и сезонное обновление.

### Case 05 — Детская Обучающая Механика

Тактильность, мелкие детали как hard constraint, разные возрастные группы.

### Case 06 — Временная Выставка

Низкий тираж, быстрая сборка, повторное использование материалов.

### Case 07 — Стерильная Среда

Неизвестная химическая совместимость; непроверенные варианты запрещены в shortlist.

### Case 08 — Один Зафиксированный Материал

Материал является hard constraint; разнообразие строится по механизму, технологии и взаимодействию без фиктивных material families.

### Case 09 — Жёсткий Бюджет И Большой Тираж

Оснастка, сборка и стоимость партии должны влиять на relative economics.

### Case 10 — Уже Выбранная Конструкция

Skill должен отказаться от дивергенции и передать задачу в workflow реализации.

## Независимая Оценка

Каждый кейс выполняют минимум два оценщика. Автор текущей версии не должен быть единственным судьёй.

Для каждого результата фиксируются:

- число концепций после feasibility;
- semantic duplicate rate;
- hard constraint violations;
- coverage по четырём осям;
- доля карточек с полными evidence и confidence;
- dominated shortlist rate;
- доля прототипных тестов с observable и failure condition;
- оценка полезности shortlist по шкале 1–5;
- разногласие оценщиков.

## Gate Для `team-ready`

- 10 из 10 кейсов имеют 5–7 концепций либо честный constraint stop;
- `hard constraint violations = 0`;
- `dominated shortlist rate = 0`;
- `semantic duplicate rate <= 10%`;
- полнота evidence/confidence не ниже 95%;
- полнота prototype tests равна 100%;
- медианная полезность shortlist не ниже 4 из 5;
- все расхождения оценщиков разобраны и отражены в examples, known exceptions или tests.

Зелёный `pytest` не заменяет этот gate.
