# Diversity Gate

## Назначение

Gate проверяет, что пользователь получил разные физические механизмы, а не коллекцию косметических вариантов одной конструкции.

## Морфологические Оси

| Ось | Примеры классов |
| --- | --- |
| Основной материал | целлюлозный лист, древесный лист, металл, жёсткий полимер, эластомер, текстиль, стекло или керамика, электронный композит |
| Технология | сгибание и биговка, лазерная резка, гибка листа, литьё, шитьё, 3D-печать, электронная сборка |
| Физическое поведение | жёсткое, упругое, тяжёлое и устойчивое, трансформируемое, магнитное, светящееся или динамическое, мягкое и тактильное |
| Взаимодействие | наблюдать, вращать, раскрывать, сжимать, переставлять, собирать, активировать |
| Жизненный цикл | одноразовый, долговечный, переносной, стационарный, ремонтопригодный, обновляемый |

Класс материала шире конкретной марки: картон и крафт-бумага — один целлюлозный класс; фанера и массив — один древесный класс, если физический механизм тот же.

## Схема Рабочей Карточки

```json
{
  "concepts": [
    {
      "id": "c1",
      "name": "Короткое имя",
      "target_action": "Что делает или понимает человек",
      "mechanism": "Как объект вызывает это действие",
      "primary_material_class": "Класс материала",
      "primary_technology": "Основная технология",
      "primary_physical_behavior": "Главное физическое поведение",
      "interaction": "Как человек взаимодействует",
      "use_conditions": "Где и как работает",
      "production_complexity": "низкая | средняя | высокая",
      "cost_class": "низкий | средний | высокий; предположение",
      "risks": ["Основной риск отказа"],
      "prototype_check": "Что доказать первым прототипом"
    }
  ],
  "shortlist": ["c1", "c3"]
}
```

## Ручная Проверка

1. Концепций не меньше пяти.
2. Для каждой заполнены все поля схемы.
3. В столбце материала нет повторов и семантических синонимов.
4. В столбце технологии нет повторов.
5. В столбце физического поведения нет повторов.
6. Механизмы нельзя описать одной фразой после удаления прилагательных.
7. Взаимодействия различаются там, где это возможно.
8. Ни одна концепция не существует только за счёт цвета, стиля или размера.
9. Shortlist содержит 2–3 концепции из веера и сохраняет осмысленный выбор, а не три почти одинаковых направления.

Если любой пункт не выполнен, результат не прошёл gate.

## Конфликт С Ограничениями

Если среда допускает, например, только моющийся негорючий материал, пять разных классов материалов могут быть небезопасны или бессмысленны. Не выдумывайте соответствие. Верните:

```text
Конфликт: какое ограничение блокирует разнообразие.
Что всё ещё возможно: сколько честно разных концепций осталось.
Один выбор пользователя: какое ограничение ослабить или принять меньшее число вариантов.
```

## Что Проверяет Скрипт

`scripts/validate_concept_fan.py` проверяет структуру и точное совпадение нормализованных значений. Он не распознаёт смысловые синонимы и не доказывает инженерную реализуемость. Поэтому после `PASS` всё равно требуется ручная проверка классов и механизмов.
