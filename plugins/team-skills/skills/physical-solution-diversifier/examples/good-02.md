# Хороший Пример: Переносной Экспонат

## Вход

«Для небольшого музейного стенда нужен предмет, который за минуту объясняет посетителю три этапа процесса. Его переносит один человек, он работает в помещении без розетки. Дай семь физически разных направлений, а не семь оформлений плаката.»

## Ожидаемое Поведение

Агент отмечает инварианты: три этапа, перенос одним человеком, помещение, автономность. Веер разводится по механикам: вращение, последовательное раскрытие, магнитная перестановка, тактильная сборка, упругая деформация, проекционная оптика без питания и механический счётчик. Для каждого направления указан класс материала, отдельная технология изготовления, физическое поведение, риск отказа и первая проверка прототипом.

Сравнительная матрица использует общие критерии: ясность последовательности, вес, скорость установки, устойчивость к многократному использованию и обновляемость содержания. Shortlist сохраняет осмысленный выбор между наиболее ясным, наиболее компактным и наиболее вовлекающим направлениями.

Нельзя считать новым концептом смену шрифта, иллюстраций или формы основания при неизменном способе взаимодействия.
