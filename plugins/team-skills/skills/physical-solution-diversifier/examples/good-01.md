# Хороший Пример: Настольная Памятка

## Вход

«Нужно разместить на рабочих столах краткую памятку о режимах рассуждения модели. Предложи не меньше шести конструкций по разной технологии, из разных материалов и с разными физическими свойствами. Объект должен привлекать внимание, занимать мало места и не требовать сети.»

## Ожидаемое Поведение

Агент фиксирует цель: сотрудник за несколько секунд выбирает подходящий режим. Затем создаёт морфологическое поле и выдаёт, например:

- складную целлюлозную призму с раскрытием;
- фанерную карусель после лазерной резки;
- магнитный набор из гнутого металла;
- упругий объект из эластомера, изготовленный 3D-печатью;
- сшитый текстильный веер;
- автономный электронный композит с переключаемым экраном.

Для каждого направления заполнены обязательные поля. Матрица показывает разные материалы, технологии, физические поведения и механизмы. После сравнения выделены 2–3 направления, но файл для печати и чертёж ещё не создаются.

## Нельзя

Нельзя выдать шесть бумажных стоек — треугольную, шестигранную, круглую и цветовые версии — и засчитать их как технологически разные решения.
