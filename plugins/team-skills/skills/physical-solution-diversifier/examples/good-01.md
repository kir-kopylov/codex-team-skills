# Хороший Пример: Пригодность Раньше Разнообразия

## Вход

«Нужно разместить на рабочих столах памятку о режимах рассуждения модели. Дай 5–7 заметных физических вариантов. Тираж — 20 штук, без сети, содержание меняется раз в квартал.»

## Ожидаемое Поведение

Агент фиксирует `target_action`, тираж и hard constraint «без сети». Сначала удаляет направления, которые требуют подключения. Затем собирает feasible-веер с coverage target по материалам, технологиям, поведению и взаимодействию.

Повтор категории допустим: две целлюлозные концепции могут остаться, если одна — дешёвая сменная карточка для пассивного чтения, а другая — раскрываемое дерево выбора с отдельной пользовательской ценностью. Повтор объясняется в `difference_rationale`; слабая электроника не добавляется только ради уникального столбца.

Для каждой концепции есть constraint results, evidence/confidence, cost drivers и прототипный falsifier. Shortlist содержит только feasible и недоминируемые направления.

## Нельзя

Нельзя максимизировать число материалов ценой худшей читаемости, обслуживания или стоимости. Нельзя считать структурный `PASS` доказательством смысловой новизны.
