# Хороший Пример: Честный Конфликт Ограничений

## Вход

«Нужна памятка для производственной зоны. Поверхность должна переносить регулярную мойку, не впитывать жидкость, не иметь текстильных или бумажных частей и соответствовать требованиям нашей службы безопасности. Всё равно дай пять вариантов из разных материалов.»

## Ожидаемое Поведение

Агент не объявляет материалы безопасными без документов и не добивает количество фиктивными различиями. Он отделяет подтверждённые ограничения от требования разнообразия и показывает конфликт: после запрета впитывающих материалов и до проверки внутренних норм пять допустимых классов материала не доказаны.

Агент может дать только честно допустимые исследовательские направления с явной пометкой «не прошли проверку службы безопасности», затем предлагает один выбор: разрешить подбор материалов по нормативам как отдельный этап либо принять меньшее число концепций до проверки. Diversity gate получает `FAIL`, а результатом становится понятный стоп.

## Нельзя

Нельзя называть пластик, металл, стекло, композит и окрашенную фанеру пригодными для зоны только ради выполнения числа пять.
