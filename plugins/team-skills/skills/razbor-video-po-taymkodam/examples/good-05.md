# Хороший Пример: Завершить Сверку С Полученными Исправлениями

## Вход

Синтетическая запись обсуждения доставки. Два распознавания дают «мы обещали доставить сегодня». Пользователь уточнил: «Оператор: мы не обещали доставить сегодня». Для другой фразы он подтвердил только слова «уточните у диспетчера», без имени говорящего. Несколько оставшихся слов неразборчивы. Готовые фрагменты уже доступны. Пользователь просит закончить без дальнейших вопросов; прямое прослушивание недоступно.

## Ожидаемое Поведение

Сохранить «не» и роль оператора по уточнению пользователя. Для второй реплики оставить неизвестного говорящего. Не продолжать опрос и повторное распознавание без нового основания. Отдать текст, пропуски и существующие аудиоссылки рядом с таймкодами в самом итоговом ответе. Назвать источники: машинные версии и уточнения пользователя; не утверждать, что звук прослушан.

## Нельзя

Нельзя считать два распознавания голосованием против человеческого уточнения, назначать говорящего по упоминанию диспетчера, восстанавливать пропуск по логике или оставлять ссылки только в сообщении о ходе.
