# Хороший Пример

## Вход

Браузерная автоматизация не может нажать кнопку отправки формы. DOM содержит кнопку, selector стабилен, screenshot показывает форму, но submit не происходит. Агент уже пробовал click, JS click и scroll. Пользователь просит "пересмотреть предпосылки".

## Ожидаемое Поведение

Агент закрывает ветку "кнопка недоступна для клика" и ищет похожие кейсы. Общий паттерн: форма блокируется невидимой валидацией или disabled-state, который не очевиден по selector. Новый gate: проверить computed disabled/aria state, validation errors и network request после submit. Действие: read-only inspect состояния элементов и event listeners, без новых blind-click.

## Нельзя

Нельзя продолжать кликать координатами или менять данные формы, пока не проверен новый gate про validation/disabled layer.
