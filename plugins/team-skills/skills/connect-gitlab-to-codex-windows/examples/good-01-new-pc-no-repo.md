# Хороший Пример: Новый Компьютер Без Репозитория

## Вход

«Подключи мою учётную запись GitLab к Codex на новом Windows-компьютере. Конкретный репозиторий пока не нужен. Хочу работать через HTTPS и иметь pull/push».

## Ожидаемое Поведение

Skill подтверждает Windows, HTTPS и один аккаунт на `gitlab.com`, затем работает по одному шагу. Он проверяет Git и GCM, ведёт пользователя к Personal Access Token, предлагает `write_repository` как scope для pull/push и не требует `api`. После создания пользователь не отправляет токен в чат, а вводит его скрыто в bundled PowerShell script. Финал — `LOCAL_CREDENTIAL_READY` с явной пометкой, что удалённый repo ещё не проверен.

## Нельзя

Нельзя требовать URL проекта, запускать clone, просить токен в чат, вставлять его в команду или обещать, что GitLab уже принял credential.
