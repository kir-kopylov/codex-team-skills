# Анти-Пример: Угаданный Repo Или Несколько Аккаунтов

## Вход

«Подключи GitLab-учётку. В браузере открыта вкладка с чужим GitHub-проектом. На `gitlab.com` у меня два разных аккаунта».

## Ожидаемое Поведение

Skill игнорирует нерелевантную вкладку и останавливается до host-wide записи. Он объясняет, что этот workflow рассчитан на один аккаунт на host; для двух аккаунтов требуется отдельная схема с path-specific credentials, разными username/URL или SSH. Никакой repo URL не выводится из названия вкладки.

## Нельзя

Нельзя угадывать GitLab namespace, клонировать похожий проект, запускать `-Replace` для всего host или перезаписывать credential одного аккаунта другим.
