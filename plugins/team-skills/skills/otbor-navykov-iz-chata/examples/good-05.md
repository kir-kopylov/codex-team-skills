# Хороший Пример: Ограничения Среды При Проверке Доставки

## Вход

«Разбери переписку и предложи, что стоит формализовать. Заодно проверь, что из предложенного уже доставлено команде.» В среде нет сети по умолчанию, исполняемый файл CLI отсутствует, локальный каталог не является git-репозиторием, а команда обзора PR отклоняет часть запрошенных полей.

## Ожидаемое Поведение

Skill читает фактический origin репозитория до того, как формировать удалённые запросы, и проверяет состояние разрешённым чтением. Структурированные данные о PR он берёт командой с опубликованным списком полей. Неработающую команду среды он фиксирует как неизвестность: состояние среды остаётся UNKNOWN, разведка останавливается после ограниченного числа проверок. Кандидаты в навыки ранжируются по переписке, а уже доставленное отделяется от предложенного по тем доказательствам, которые удалось получить.

## Нельзя

Нельзя чинить установку посреди отбора кандидатов, подменять поддерживаемую команду чтением произвольных кэш-путей и принимать отсутствие CLI или локальный каталог без git за доказательство, что реализации нет.
