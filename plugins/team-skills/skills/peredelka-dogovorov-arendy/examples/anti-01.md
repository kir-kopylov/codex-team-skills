# Анти-Пример: Разовое Изменение Суммы Аренды

## Вход

Пользователь пишет: "Сделай допсоглашение — с июля временно снижаем аренду на
одну сумму, наймодатель тот же, ничего больше не меняется".

## Ожидаемое Поведение

Codex не ведет это через `peredelka-dogovorov-arendy`: наймодатель не меняется,
переоформления пакета нет, речь только о разовом изменении суммы аренды. Codex
объясняет, что для такой задачи есть более узкий skill `dopsoglasheniya-po-oplate`,
и предлагает применить его вместо разворачивания полного цикла разведки,
forensic-аудита и планирования пакета.

## Нельзя

Нельзя запускать Фазы 1-6 (разведку, forensic-аудит, планирование пакета) ради
одного простого допсоглашения по сумме и нельзя молча менять сторону договора
или структуру пакета, когда пользователь этого не просил.
