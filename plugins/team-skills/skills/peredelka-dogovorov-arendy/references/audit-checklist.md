# Чеклист forensic-аудита договора найма

## 1. Идентификация сторон
- [ ] ФИО, ИИН обеих сторон — заполнены
- [ ] Документ удостоверения Наймодателя (УДО) — номер, дата, орган, срок
- [ ] Документ Нанимателя (паспорт/УДО) — номер, дата, орган, срок
- [ ] РВП (если иностранец) — номер, даты начала/окончания, орган
- [ ] РВП действителен на дату подписания договора
- [ ] Адреса проживания обеих сторон
- [ ] Телефоны / контактные лица
- [ ] Реквизиты карты/счёта для платежей

## 2. Предмет договора
- [ ] Адрес объекта — полный, включая район
- [ ] Площадь — заполнена (не ____)
- [ ] Этаж — заполнен (не __)
- [ ] РКА и кадастровый номер
- [ ] Правоустанавливающий документ — указан конкретно (номер, дата)
- [ ] Правоустанавливающий документ — есть копия в папке проекта

## 3. Сроки и пролонгация
- [ ] Дата начала и дата окончания — конкретные числа
- [ ] Срок = разница дат (проверить арифметику)
- [ ] Условия пролонгации — срок уведомления о непродлении
- [ ] Нет конфликта между сроком уведомления и сроком пролонгации

## 4. Платежи
- [ ] Сумма аренды — цифрой и прописью
- [ ] Дата первого платежа
- [ ] Дата последующих платежей
- [ ] Реквизиты для перечисления — банк, счёт, БИК, получатель
- [ ] Коммуналка — кто платит, как контролируется
- [ ] Пеня за просрочку — размер, порядок начисления

## 5. Бюджет улучшений
- [ ] Лимит по месяцам — какие месяцы фиксированные, какие условные
- [ ] Месяцы названы по именам (не «1-й», «2-й»)
- [ ] Нет противоречия между п. 3.3 и п. 3.4 (какой месяц куда попадает)
- [ ] Правило «нет чека — нет вычета» — с какого месяца действует
- [ ] Перенос превышения — механизм описан, требует предварительного согласования
- [ ] Остаток неизрасходованного бюджета — возвращается деньгами или переносится
- [ ] Документооборот: чек + фото «до» + фото «после»

## 6. Ответственность
- [ ] «Нормальный износ» — есть ли хоть какое-то определение или перечень
- [ ] Атрибуция поломок техники — кто определяет «по чьей вине»
- [ ] Порог неучитываемого ущерба — по позиции или по совокупности
- [ ] Капитальный ремонт — за чей счёт

## 7. Расторжение
- [ ] п. 5.2 (одностороннее) привязан к п. 5.4–5.5 (последствия)
- [ ] п. 5.3 — «нарушение» определено закрытым перечнем с порогами
- [ ] п. 5.4 — «обоснованное/необоснованное» определено закрытым перечнем
- [ ] п. 5.5 — компенсация при расторжении покрывает ВЕСЬ непогашенный остаток
- [ ] Штраф за необоснованное расторжение — конкретная сумма
- [ ] Повышение аренды — есть cap (%) и право нанимателя уйти с сохранением компенсации

## 8. Акт приёма-передачи
- [ ] Показания счётчиков — заполнены цифрами
- [ ] Количество ключей/пультов/карт — заполнено
- [ ] Опись имущества — заполнена (не пустая таблица)
- [ ] Фото квартиры при заселении — подшиты/приложены

## 9. Форс-мажор
- [ ] Механизм подтверждения наступления форс-мажора
- [ ] Канал уведомления — конкретный
- [ ] Влияние на непогашенный остаток улучшений — описано

## 10. Системные проверки
- [ ] Все документы пакета на одном формате страницы (A4)
- [ ] Поля одинаковые во всех документах
- [ ] Подписные блоки в едином стиле
- [ ] Перекрёстные ссылки между документами — корректны
- [ ] Математика бьётся сквозь все документы
- [ ] Нет NULL-полей в подписанных документах
