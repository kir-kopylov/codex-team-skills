# Начать Здесь: Перевести Старую Установку

Этот вход нужен компьютеру, где Team Skills подключались локальной копией или фоновым обновлением, в том числе когда plugin уже установлен, а marketplace не обновляется.

Прочитай целиком [процедуру переподключения](plugins/team-skills/skills/obnovlenie-biblioteki-navykov/references/reconnect.md) и выполни её в пределах запроса пользователя. Она входит в поставляемый plugin: установленный навык читает соседний `references/reconnect.md` без локального checkout репозитория.

Процедура проверяет официальный CLI и владение источником, сохраняет конфигурацию и пакет до замены, проверяет сохранность нужных доработок и только затем переподключает штатный Git marketplace. Не выполняй удаление по памяти или по одной этой краткой странице.
