# Гид Для Организатора Onboarding

Коллеге отправляйте [START_HERE_CONNECT_CODEX_SKILLS.md](START_HERE_CONNECT_CODEX_SKILLS.md). Если старая установка уже существовала, отправляйте [START_HERE_RECONNECT_CODEX_SKILLS.md](START_HERE_RECONNECT_CODEX_SKILLS.md).

## Что Теперь Делает Codex

Codex проверяет собственную версию, подключает публичный Git marketplace и устанавливает plugin штатной командой. Пользовательские `.cmd`, PowerShell-скрипты, shell-скрипты и отдельный фоновый updater не распространяются.

Минимальная поддерживаемая версия — Codex `0.144.4`. При более старой версии агент останавливается и просит обновить Codex.

## Что Отправить Коллеге

```text
Загрузи этот .md файл в Codex Desktop и напиши: «Установи эту библиотеку skills и проверь результат».
```

Агент сам выполняет штатные команды. Пользователь не должен отключать Defender, добавлять исключения или запускать скачанные команды.

## Проверка Результата

Установка доказана только если:

1. marketplace и plugin вернули успешный JSON без ошибок;
2. `codex plugin list --json` показывает `team-skills` как установленный и включённый;
3. пользователь полностью перезапустил Codex;
4. новая сессия видит контрольный team-skill.

Файл на диске не доказывает, что текущая сессия уже загрузила plugin.

## Старые Установки

Переход начинается со снимка состояния и штатного удаления. Старые каталоги, конфигурация, задача Windows или LaunchAgent macOS удаляются только после доказательства точной принадлежности. При несовпадении агент останавливается; массовое удаление и новый скачиваемый очиститель запрещены.

## Обновление И Удаление

Команды приведены в [quickstart.md](quickstart.md). После каждой операции требуется полный перезапуск Codex и отдельная runtime-проверка.

## Author Mode

Автор создаёт branch, меняет skill, повышает semver Codex plugin, запускает `python -m pytest` и открывает Pull Request. Доставка Claude Code остаётся отдельным контрактом и проверяется своим smoke-тестом.
