# Переименование Skills 2026-09

В сентябре 2026 года в библиотеку добавлено правило имени skill (раздел «Имя Skill» в `CONTRIBUTING.md`): имя латиницей из русских слов, чтобы по одному названию было ясно, что делает навык и в какой момент он нужен. Все навыки с английскими именами переименованы одним изменением; версия Codex plugin поднята до `0.8.0`. Содержимое навыков, их русские названия в строке запуска и естественные фразы-триггеры не менялись. `goal-contract-shaper-v3` не переименован: его удаляет отдельный PR #166.

## Что Сделать Коллеге

1. **Явные вызовы.** Везде, где вы вызывали skill по имени (`$старое-имя`, инструкции с `team-skills:<старое-имя>`), подставьте новое имя из таблицы. Естественные фразы работают как раньше.
2. **Личные копии.** Если у вас есть личный skill (папка без маркера `.team-skill`) с именем, совпадающим с **новым** именем из таблицы, `scripts/pull-skills.sh` его не перезапишет: такой навык будет пропущен с предупреждением «КОЛЛИЗИЯ» в `.sync.log` и счётчиком `collisions` в `.last-sync`. Чтобы получить командную версию, переименуйте или удалите личную папку и повторите синхронизацию. Старые командные копии с маркером синхронизация удалит сама.
3. **Журналы навыков.** Журналы `usage-feedback.jsonl`, `exception-log.jsonl` и проб живут в `~/.codex/skill-runs/<имя>/`. После переименования они не переезжают сами: перенесите папки, иначе история сбоев и проб начнётся с нуля.

4. **Локальная копия marketplace Codex.** Если ваш `~/.codex/config.toml` указывает на локальную копию plugin, обновите её навыком `obnovlenie-biblioteki-navykov` или переподключите git-источник по `START_HERE_RECONNECT_CODEX_SKILLS.md`: в замороженной копии останутся старые имена.
5. **Открытые ветки.** Ветки и stash, созданные до переименования, при rebase на `main` дают конфликты по переименованным путям; применяйте изменения с определением переименований (`git rebase` по умолчанию, `git apply -3` для stash).
