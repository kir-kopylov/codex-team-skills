# Общее Хранилище Скиллов

`codex-team-skills` — командная библиотека проверенных skills, а не один prompt и не отдельная система обновления.

## Из Чего Она Состоит

- `catalog.md` помогает найти skill по задаче;
- `plugins/team-skills` упаковывает skills как plugin Codex и Claude Code;
- `.agents/plugins/marketplace.json` публикует plugin штатному marketplace Codex;
- `skill.yaml`, examples и known exceptions фиксируют назначение и границы;
- tests и CI проверяют структуру, приватность, язык, semver и реальную установку;
- `scripts/pull-skills.sh` сохраняет отдельный folder-sync путь Claude Code.

## Роли

Пользователь подключает Git marketplace штатными командами Codex, перезапускает приложение и выбирает skill обычной фразой.

Автор создаёт или меняет skill, повышает версию plugin, добавляет проверки и открывает Pull Request.

Ревьюер проверяет пользу, границы, приватность и evidence. Администратор следит за CI и понятным входом для коллег.

## Что Является Успехом

Коллега должен быстро понять:

1. какие skills доступны;
2. какой фразой запустить нужный skill;
3. когда его применять нельзя;
4. как штатно установить, обновить и удалить plugin;
5. как предложить изменение через Pull Request.

## Что Не Является Целью

Repo не должно превращаться в архив случайных prompts, хранилище приватных данных, собственную платформу доставки или фоновую службу обновления. Достаточны каталог, plugin, Git marketplace, tests и понятный onboarding.
