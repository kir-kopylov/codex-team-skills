# Общее Хранилище Скиллов

`codex-team-skills` — это не один skill и не проект про фотобомбинг. Это командная платформа для хранения, проверки, установки и развития Codex skills.

## Зачем Оно Нужно

Команда постепенно накапливает повторяемые рабочие приёмы: как проверять документы, как готовить отчёты, как редактировать изображения, как вести onboarding, как не терять контекст. Если хранить это только в чатах, знания быстро расползаются и теряются.

Это repo делает такие практики переиспользуемыми:

- `catalog.md` помогает найти skill по задаче;
- `plugins/team-skills` упаковывает все skills как один plugin для Codex;
- `skill.yaml` фиксирует владельца, статус, use cases и ограничения;
- `examples/` показывают, как skill должен и не должен работать;
- `tests/` и CI не дают сломать структуру, приватность и языковой контракт;
- CI собирает проверенный `team-skills-bundle.zip` и `manifest.json`;
- `installer/` ставит plugin пользователям, включает автообновление, показывает status и удаляет установку;
- `scripts/install_plugin.sh` остаётся прямым локальным путём для авторов и разработчиков repo;
- `scripts/new_skill.py` создаёт черновик нового skill по единому шаблону.

## Как Думать О Ролях

- Пользователь skills ставит проверенный bundle через installer, открывает каталог, выбирает задачу и пишет Codex обычную фразу.
- Автор skills создаёт новый skill, добавляет примеры, запускает тесты и открывает Pull Request.
- Ревьюер проверяет пользу, границы применения, приватность и наличие evidence.
- Админ repo следит, чтобы публичный `main` оставался рабочим, без приватных данных и с понятным входом для коллег.

## Что Является Успехом

Коллега должен за 5 минут понять:

1. какие командные skills доступны;
2. какой фразой запустить нужный skill;
3. когда skill применять нельзя;
4. как обновить локальный plugin;
5. как предложить новый skill без ручной сборки структуры.

## Что Не Является Целью

Это repo не должно превращаться в:

- архив случайных prompts без owners и примеров;
- набор личных рабочих заметок;
- место хранения приватных данных;
- жёсткую платформу с тяжёлым release process раньше реального использования.

V1 намеренно лёгкий: каталог, plugin, шаблон, examples, tests и понятный onboarding.
