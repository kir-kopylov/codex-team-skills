# Отказ От Самодельной Доставки Codex

Дата решения: 19 июля 2026 года.

## Что Произошло

На Windows Microsoft Defender заблокировал старую пользовательскую команду как `Trojan:Win32/ClickFix.DEG!MTB`. Команда скачивала временный командный файл, немедленно запускала его и удаляла. Такое поведение само по себе совпадает с распространённой схемой социальной инженерии, независимо от намерений авторов библиотеки.

Срабатывание не доказывает вредоносность содержимого repo и не считается доказанной ложной тревогой. Публичный raw-отчёт, скриншоты, личные пути и полные журналы в repo не добавляются.

## Принятое Решение

- самодельная доставка для Codex полностью удаляется на всех ОС;
- установка, обновление и удаление выполняются штатным `codex plugin`;
- пользователю не предлагается отключать Defender или добавлять исключения;
- старые установки переводятся локально и только после доказательства владения каждым объектом;
- отдельные исполняемые файлы доставки больше не публикуются.

## Проверка

CI устанавливает минимально поддерживаемый Codex `0.144.4` на Windows и macOS и в изолированном `CODEX_HOME` проверяет локальный и Git-источник: подключение marketplace, установку, повторную установку, обновление и удаление.

Локальная проверка 19 июля 2026 года в 22:43 `+05:00`: Windows 10 Pro build `19045`, Codex `0.144.4`, Defender engine `1.1.26060.3008`, сигнатуры `1.455.222.0` от 14:39. Antivirus и real-time protection были включены. После установки, повторной установки и удаления plugin `0.2.0` через локальный native marketplace новых обнаружений в проверенном 30-минутном окне не было.

Это доказательство относится только к указанной машине и временному окну. Оно не доказывает отсутствие обнаружений на других конфигурациях. Проверка Git-источника на Windows и macOS выполняется CI; отдельная проверка на чистой Windows 11 с актуальной штатной защитой остаётся эксплуатационным gate перед общим утверждением о совместимости с Defender.
