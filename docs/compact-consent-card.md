# Компактная Карточка Согласия

Статус: единый обязательный контракт для всех навыков.

## Канонический Формат

Применить **«<понятное русское название>»** (<author_github>) для <кратко назовите действие и объект>?

**С навыком:** <назовите только дополнительную процедуру или проверяемый результат>.

**Без навыка:** <назовите только результат без этой процедуры или проверки>.

## Проверяемые Требования

1. Карточка содержит ровно три непустые строки и не более 45 слов.
2. Вопрос о применении стоит первым; действие и объект задачи называются только в нём.
3. Автор указан в скобках в первой строке через подтверждённый `author_github`.
4. «С навыком» и «Без навыка» занимают по одной строке и одному предложению.
5. Сравнительные строки показывают только различие и не пересказывают запрос.
6. Неизвестные сведения не добавляются.
7. Нет вводного анализа, отдельной строки ограничения, таблицы, кодовой рамки и заголовка `Annotation N`.
8. Если реальное ограничение меняет выбор, оно кратко помещается в подходящую сравнительную строку.
9. Для `status: experimental` статус и `owner` для обратной связи находятся в скобках первой строки и не создают четвёртую строку.

## Общий Контракт

Миграция завершена: формат обязателен для каждого `SKILL.md` и для генератора новых навыков. Подробная карточка с формулой «Для вашей задачи —» и старый гейт с вопросом «Применить или решить без него?» запрещены единым тестовым контрактом.
